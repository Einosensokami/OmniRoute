`devin-cli-agentic` ପ୍ରକୃତ Claude Code ରନ୍ଟାଇମ୍କୁ OmniRouteର ସ୍ଥାନୀୟ Anthropic
Messages ଏଣ୍ଡପଏଣ୍ଟ ବ୍ୟବହାର କରିବାକୁ ଦିଏ, ଯେତେବେଳେ ଆଧିକାରିକ Devin CLI, ACP stdio ମାଧ୍ୟମରେ ମଡେଲ୍ ପ୍ରତିକ୍ରିୟା ଯୋଗାଏ। ଏହା
ବିଦ୍ୟମାନ Anthropic, Claude OAuth, Claude Web, କିମ୍ବା `devin-cli` ପ୍ରଦାନକାରୀଗୁଡ଼ିକୁ ପରିବର୍ତ୍ତନ କରେ ନାହିଁ।

କ୍ଲାଏଣ୍ଟ-ମାଲିକାନାର ଟୁଲ୍ କଲ୍ଗୁଡ଼ିକ ପାଇଁ, Claude-ଫର୍ମାଟ୍ ଟୁଲ୍-ସକ୍ଷମ ପ୍ରଦାନକାରୀ
`devin-cli-agentic` (ଉପନାମ `dva`) ମାଧ୍ୟମରେ ରୁଟ୍ କରନ୍ତୁ। ପୁରୁଣା `devin-cli` (`dv`) ACP ଏକ୍ସିକ୍ୟୁଟର୍
କେବଳ-ଟେକ୍ସଟ୍: ଏହା Devinର ଟୁଲ୍-ବିହୀନ ସାରାଂଶକାରୀକୁ ଚଲାଏ ଏବଂ ଟୁଲ୍ କଲ୍ ଫେରାଇ ପାରେ ନାହିଁ। ଏହାର ମଡେଲ୍
ମେଟାଡାଟାକୁ ସେହି ଅନୁସାରେ ଚିହ୍ନିତ କରାଯାଇଛି, ଯାହାଫଳରେ ଟୁଲ୍-ଆବଶ୍ୟକ କମ୍ବୋ ରୁଟିଂ ଏହାକୁ ଏଡ଼ାଇବ।

> **ବର୍ତ୍ତମାନ ସ୍ଥିତି: Claude Code `2.1.258`ରେ ପିନ୍ କରାଯାଇଛି; ଅଫ୍ଲାଇନ୍ ଏବଂ ଲାଇଭ୍ ବୈଧତା ଯାଞ୍ଚ ଶେଷ ଥର
> `2.1.220`ରେ ରେକର୍ଡ କରାଯାଇଥିଲା।** `2.1.220` ପିନ୍ଟି Devin CLI
> `3000.2.17` ଏବଂ ମଡେଲ୍ `swe-1-7-lightning` ମାଧ୍ୟମରେ ତିନୋଟି ପୃଥକ ପରିଦୃଶ୍ୟ ସମ୍ପୂର୍ଣ୍ଣ କରିଥିଲା; ସେହି ଅନ୍ତିମ ଲାଇଭ୍ ରନ୍ କ୍ଲାଏଣ୍ଟ-ମାଲିକାନାର `Read`,
> `Edit`, ଏବଂ `Bash` ଟର୍ନ୍, ସଫଳ `npm test` ଫଳାଫଳ, ପ୍ରକଳ୍ପ କମାଣ୍ଡ ଏବଂ ସ୍କିଲ୍
> ଆବିଷ୍କାର, କେବଳ-Devin ରୁଟିଂ, ଏବଂ ଶୂନ୍ୟ Claude ଇଗ୍ରେସ୍ ପ୍ରମାଣ କରିଥିଲା। ତା’ପରେ ପିନ୍କୁ `2.1.258`କୁ ବୃଦ୍ଧି କରାଯାଇଥିଲା
> (ଯେଉଁ CLI ପିଢ଼ିକୁ OmniRouteର Claude ପରିଚୟ ଅନୁକରଣ କରେ, ଏବଂ ଯେଉଁ ପ୍ରଥମ ଲାଇନ୍
> ସ୍ୱଦେଶୀ ଭାବେ Fable 5.1 ସ୍ତର ସହିତ ଆସେ)। ନୂଆ ପିନ୍ରେ, ପିନ୍ କରାଯାଇଥିବା ବେସ୍ ଇମେଜ୍ରେ ଇନ୍ଷ୍ଟଲ୍ ସ୍ତର ଏବଂ `claude --version`
> ଯାଞ୍ଚ କରାଯାଇଥିଲା, ଏବଂ ବ୍ରିଜ୍ ୟୁନିଟ୍ ସୁଇଟ୍, `compose config` ଓ
> ସ୍ଥିର ବିଚ୍ଛିନ୍ନତା ପ୍ରମାଣ ସଫଳ ହୋଇଛି — କିନ୍ତୁ ଅଫ୍ଲାଇନ୍ ମକ୍ ପରିଦୃଶ୍ୟ ଏବଂ ଲାଇଭ୍ ତିନି-ପରିଦୃଶ୍ୟ
> ସୁଇଟ୍କୁ ଏପର୍ଯ୍ୟନ୍ତ ପୁନଃ ଚଲାଯାଇନାହିଁ। ଏହି ପିନ୍ ସହିତ ବ୍ରିଜ୍ରେ ନିର୍ଭର କରିବା ପୂର୍ବରୁ ସେଗୁଡ଼ିକୁ ପୁନଃ ଚଲାନ୍ତୁ ("ପିନ୍ କରାଯାଇଥିବା ଟୁଲ୍ଗୁଡ଼ିକୁ ଅଦ୍ୟତନ କରିବା" ଦେଖନ୍ତୁ)।

## ସ୍ଥାପତ୍ୟ

```text
Claude Code 2.1.258 (ବିଚ୍ଛିନ୍ନ ଅଣ-root Linux କଣ୍ଟେନର୍)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (Claude-ଫର୍ମାଟ୍, ପ୍ରମାଣୀକରଣ-ବିହୀନ ପ୍ରଦାନକାରୀ)
  -> devin acp --agent-type summarizer (ଆଧିକାରିକ ACP stdio, Devin ଟୁଲ୍ ବିହୀନ)
  -> ଉତ୍ସର୍ଗୀକୃତ devin-auth ଭଲ୍ୟୁମ୍ରେ Devin ଆକାଉଣ୍ଟ
```

ଆଧିକାରିକ CLIର ଡିଫଲ୍ଟ ACP ଏଜେଣ୍ଟ ନିଜର ଟୁଲ୍ଗୁଡ଼ିକୁ ଏକ୍ସିକ୍ୟୁଟ୍ କରିପାରେ, ତେଣୁ ଏହି ବ୍ରିଜ୍ ଏହାକୁ ବ୍ୟବହାର କରେ ନାହିଁ।
ଏହା ସ୍ଥିର `summarizer` ACP ଏଜେଣ୍ଟକୁ ଆରମ୍ଭ କରେ, ଯାହାର ଆଧିକାରିକ CLI ମୋଡ୍ରେ କୌଣସି ଟୁଲ୍ ନାହିଁ, ଏବଂ
କ୍ରମିକୀକୃତ Anthropic ଅନୁରୋଧକୁ ଏକ ନିଷ୍ପାଦନ ଟ୍ରେସ୍ ଭାବରେ ଫ୍ରେମ୍ କରେ। ଯେତେବେଳେ ଅନ୍ୟ ଏକ Claude-ମାଲିକାନାର
କାର୍ଯ୍ୟ ଆବଶ୍ୟକ ହୁଏ, ପ୍ରତିକ୍ରିୟାରେ ଠିକ୍ ଗୋଟିଏ କ୍ଲାଏଣ୍ଟ ଟୁଲ୍ ଏନ୍ଭେଲୋପ୍ ରହିବା ଆବଶ୍ୟକ। କୌଣସି ACP
`tool_call` କିମ୍ବା `tool_call_update`କୁ ପ୍ରତିକ୍ରିୟା ସଫଳ ବୋଲି ରିପୋର୍ଟ କରାଯିବା ପୂର୍ବରୁ ପ୍ରତ୍ୟାଖ୍ୟାନ କରାଯାଏ।

`open-sse/executors/devin-agentic/serializer.ts`ରେ ଥିବା ସିରିଆଲାଇଜର୍ `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice`, ଏବଂ
Claude Code ଦ୍ୱାରା ଯୋଗାଇ ଦିଆଯାଇଥିବା ଟୁଲ୍ଗୁଡ଼ିକୁ ସଂରକ୍ଷଣ କରେ। ଇମେଜ୍ ଏବଂ ଅଜଣା ବ୍ଲକ୍ଗୁଡ଼ିକ ସ୍ପଷ୍ଟ ଭାବେ ବିଫଳ ହୁଏ। ବଡ଼ ଟୁଲ୍ ଫଳାଫଳ
ଏକ ଦୃଶ୍ୟମାନ ଛାଟିବା ସୂଚକ ବ୍ୟବହାର କରେ।

ପାର୍ସର୍ ପ୍ରତ୍ୟେକ ମଡେଲ୍ ଟର୍ନ୍ରେ ଗୋଟିଏ ସ୍ୱତନ୍ତ୍ର `<tool>{...}</tool>` ଏନ୍ଭେଲୋପ୍ ଗ୍ରହଣ କରେ। ଏହା
ଅନୁରୋଧର ଟୁଲ୍ ତାଲିକା ବିପରୀତରେ ନାମ ଯାଞ୍ଚ କରେ, ସେହି ଟୁଲ୍ର JSON
Schema ବିପରୀତରେ ଆର୍ଗୁମେଣ୍ଟଗୁଡ଼ିକୁ ବୈଧ କରେ, ମିଶ୍ରିତ ବର୍ଣ୍ଣନା/କାର୍ଯ୍ୟକୁ ପ୍ରତ୍ୟାଖ୍ୟାନ କରେ, ଏବଂ ଗୋଟିଏ ସୀମିତ ମରାମତିକୁ ଅନୁମତି ଦିଏ। ତା’ପରେ Claude Code
ଫଳସ୍ୱରୂପ ମିଳିଥିବା Anthropic `tool_use`କୁ ସ୍ଥାନୀୟ ଭାବେ ଏକ୍ସିକ୍ୟୁଟ୍ କରେ ଏବଂ `tool_result`କୁ OmniRoute ମାଧ୍ୟମରେ ପୁଣି ପଠାଏ।

## ସ୍ୱୟଂଚାଳିତ ରୁଟିଂ

ପ୍ରଦାନକାରୀଟି ବ୍ଲକ୍ ହୋଇନଥିବାବେଳେ OmniRouteର `auto/*` ପ୍ରାର୍ଥୀ ପୁଲ୍ଗୁଡ଼ିକରେ ଯୋଗ୍ୟ ଅଟେ।
ପ୍ରାର୍ଥୀ ଯୋଗ୍ୟତା ଚୟନକୁ ସୁନିଶ୍ଚିତ କରେ ନାହିଁ: କମ୍ବୋର ରୁଟିଂ କୌଶଳ (ଉଦାହରଣ ସ୍ୱରୂପ,
ଶେଷ-ଜଣା-ଭଲ) ଅନ୍ୟ ଏକ ପ୍ରଦାନକାରୀକୁ ପସନ୍ଦ କରିପାରେ। ଯେତେବେଳେ ଆପଣ ପ୍ରତ୍ୟେକ ଅନୁରୋଧ Devin ମାଧ୍ୟମରେ ଯିବା ଆବଶ୍ୟକ କରନ୍ତି,
`dva/<model>` କିମ୍ବା Devin-ପ୍ରଥମ କମ୍ବୋ ବ୍ୟବହାର କରନ୍ତୁ।

## ପୃଥକୀକରଣ ଏବଂ ବିପଦ ମଡେଲ୍

ହୋଷ୍ଟର Claude ଇନ୍ଷ୍ଟଲେସନ୍, ଆକାଉଣ୍ଟ ଏବଂ କନଫିଗରେସନ୍ ଏହାର ପରିସର ବାହାରେ ଅଛି ଏବଂ ସେଗୁଡ଼ିକୁ
ନିଷିଦ୍ଧ ଭାବେ ବିବେଚନା କରାଯାଏ। Compose ସେବାଗୁଡ଼ିକ:

- UID/GID `10001:10001` ଭାବରେ, କେବଳ-ପଠନୀୟ ରୁଟ୍ ଫାଇଲ୍ସିଷ୍ଟମ୍, ବର୍ଜିତ କ୍ଷମତା ଏବଂ
  `no-new-privileges` ସହିତ ଚାଲେ;

ଅଫ୍ଲାଇନ୍ ପ୍ରୋଫାଇଲ୍ ଏକ ଆଭ୍ୟନ୍ତରୀଣ ନେଟୱର୍କ ବ୍ୟବହାର କରେ। ଲାଇଭ୍ ପ୍ରୋଫାଇଲ୍ରେ, OmniRoute କେବଳ
`network-guard` ମାଧ୍ୟମରେ ଆଧିକାରିକ Devin ଏଣ୍ଡପଏଣ୍ଟଗୁଡ଼ିକୁ ପହଞ୍ଚେ; ଅସମ୍ପର୍କିତ ଗନ୍ତବ୍ୟସ୍ଥଳଗୁଡ଼ିକୁ ବାରଣ କରାଯାଏ।
Claude Codeର ଏକ ଅଲଗା ସମସ୍ତ-ଇଗ୍ରେସ୍-ଅସ୍ୱୀକାର ଗାର୍ଡ ରହିଛି ଏବଂ ଏହା `NO_PROXY` ମାଧ୍ୟମରେ କେବଳ ସ୍ଥାନୀୟ OmniRoute
ସେବାକୁ ପହଞ୍ଚିପାରେ। ଗାର୍ଡ ଅଡିଟ୍ ଫାଇଲ୍ଗୁଡ଼ିକ କେବଳ ସେମାନଙ୍କ ଗାର୍ଡ ପ୍ରକ୍ରିୟା ଦ୍ୱାରା ମାଉଣ୍ଟ କରାଯାଏ। ସ୍କ୍ରିପ୍ଟଗୁଡ଼ିକ
ଟୋକେନ୍-ମୁକ୍ତ ପ୍ରମାଣ ଏକ୍ସପୋର୍ଟ କରିବା ପୂର୍ବରୁ ଫାଇଲ୍ ମାଲିକାନା, ମୋଡ୍, ଲିଙ୍କ୍ ସଂଖ୍ୟା ଏବଂ ପ୍ରତ୍ୟେକ ନିଷ୍ପତ୍ତିକୁ ଯାଞ୍ଚ କରନ୍ତି।

ପୃଥକୀକରଣ ପ୍ରମାଣକୁ ସ୍ୱାଧୀନ ଭାବେ ଚଲାନ୍ତୁ:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

ଏହା ଟୋପୋଲୋଜି, ନାମିତ ମାଉଣ୍ଟ, ଅଣ-ରୁଟ୍/କେବଳ-ପଠନୀୟ ସେଟିଂସ୍, ସ୍ପଷ୍ଟ ସ୍ଥାନୀୟ ରାଉଟିଂ,
ସମ୍ବେଦନଶୀଳ ପରିବେଶ ଭେରିଏବଲ୍ର ଅନୁପସ୍ଥିତି, Docker ସକେଟ୍ର ଅନୁପସ୍ଥିତି, `api.anthropic.com` ଏବଂ
`claude.ai`କୁ ଅବରୋଧିତ ପ୍ରବେଶ, କେବଳ Devin ପ୍ରଦାନକାରୀ ଚୟନ ଏବଂ ACP ବ୍ୟାକ୍ଏଣ୍ଡ ଅନୁପଲବ୍ଧ ଥିବାବେଳେ
ସ୍ପଷ୍ଟ ବିଫଳତାକୁ ବୈଧ କରେ।

## ପ୍ରଥମ ଥର ସେଟଅପ୍ ଏବଂ ସାଧାରଣ ବ୍ୟବହାର

ପିନ୍ କରାଯାଇଥିବା ଇମେଜ୍ ନିର୍ମାଣ କରନ୍ତୁ:

```bash
./scripts/devin-bridge/build
```

କେବଳ ପୃଥକୀକୃତ Devin ଭଲ୍ୟୁମ୍କୁ ପ୍ରମାଣୀକୃତ କରନ୍ତୁ:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

ଲଗ୍ଇନ୍ କମାଣ୍ଡ ରିମୋଟ୍/କଣ୍ଟେନର୍ ପରିବେଶ ପାଇଁ ଉଦ୍ଦିଷ୍ଟ ଆଧିକାରିକ ମାନୁଆଲ୍-ଟୋକେନ୍ ପ୍ରବାହ ବ୍ୟବହାର କରେ।
ମୂଲ୍ୟଟି ସିଧାସଳଖ CLI ପ୍ରମ୍ପ୍ଟରେ ପ୍ରବେଶ କରାଯାଏ; ଏହାକୁ ଏକ ପ୍ରକ୍ରିୟା ଆର୍ଗୁମେଣ୍ଟ ଭାବରେ ପଠାଯାଏ ନାହିଁ,
Gitରେ ଲେଖାଯାଏ ନାହିଁ କିମ୍ବା ହୋଷ୍ଟରୁ କପି କରାଯାଏ ନାହିଁ।

ପୃଥକୀକୃତ Claude Code ରନ୍ଟାଇମ୍ ଲଞ୍ଚ୍ କରନ୍ତୁ:

```bash
./scripts/devin-bridge/launch
```

`launch` କଣ୍ଟେନର୍କୃତ Claude Code ଆରମ୍ଭ କରିବା ପୂର୍ବରୁ ପୃଥକୀକରଣ, Devin ପ୍ରମାଣୀକରଣ ଏବଂ ମଡେଲ୍ ଆବିଷ୍କାରକୁ
ପୁନଃଯାଞ୍ଚ କରେ। ଏହା କଦାପି ହୋଷ୍ଟର Claude ଏକ୍ସିକ୍ୟୁଟେବଲ୍ ଚଲାଏ ନାହିଁ। ମଡେଲ୍ ଉପନାମଗୁଡ଼ିକୁ
`.env.devin-bridge`ରେ ସେଟ୍ କରାଯାଇପାରେ; ପ୍ରତ୍ୟେକ କନଫିଗର୍ କରାଯାଇଥିବା ମୂଲ୍ୟରେ
`devin-cli-agentic/` ଉପସର୍ଗ ରହିବା ଆବଶ୍ୟକ।

## ବୈଧତା ପରୀକ୍ଷା କମାଣ୍ଡଗୁଡ଼ିକ

ପୁନରୁତ୍ପାଦନଯୋଗ୍ୟ ଅଫ୍ଲାଇନ୍ ପଥ ପାଇଁ କୌଣସି Devin ଆକାଉଣ୍ଟ ଆବଶ୍ୟକ ନୁହେଁ ଏବଂ ଏଥିରେ ରନ୍ଟାଇମ୍ ଇଣ୍ଟରନେଟ୍ ନାହିଁ:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

ପ୍ରମାଣୀକୃତ ଇଚ୍ଛାଧୀନ ଲାଇଭ୍ ପଥଟି ହେଉଛି:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

ACP ସେସନ୍ଗୁଡ଼ିକୁ ଏକାସାଙ୍ଗରେ ବହୁ ସଂଖ୍ୟାରେ ଖୋଲିବାରୁ ଏଡ଼ାଇବା ପାଇଁ ଲାଇଭ୍ ରନର୍ ପରିଦୃଶ୍ୟଗୁଡ଼ିକ ମଧ୍ୟରେ ଅପେକ୍ଷା କରେ ଏବଂ
ପାଠ୍ୟ ଦାବିକୁ ବିଶ୍ୱାସ କରିବା ପରିବର୍ତ୍ତେ ସଂରଚିତ Claude ଷ୍ଟ୍ରିମ୍ ଇଭେଣ୍ଟଗୁଡ଼ିକୁ ବୈଧ କରେ। ଏହାର ତିନୋଟି
ପରିଦୃଶ୍ୟ ନିମ୍ନଲିଖିତଗୁଡ଼ିକୁ ପ୍ରମାଣ କରେ:

1. ସିଧାସଳଖ ପ୍ରକଳ୍ପ ପଠନ ଏବଂ ତ୍ରୁଟି ବିଶ୍ଳେଷଣ;
2. ଏକ ପ୍ରକୃତ `Edit`, କ୍ଲାଏଣ୍ଟ-ମାଲିକାନାଧୀନ `Bash` `npm test` ଏବଂ ଏକ ଟର୍ମିନାଲ୍ ଫଳାଫଳ;
3. `/bridge-check` ସହିତ `bridge-proof` ଆବିଷ୍କାର, ପ୍ରକଳ୍ପ ପଠନ, ଅନ୍ୟ ଏକ ସଫଳ
   କ୍ଲାଏଣ୍ଟ-ମାଲିକାନାଧୀନ `npm test` ଏବଂ କୌଣସି ବିଚାରାଧୀନ କାର୍ଯ୍ୟ ବିନା ସମାପ୍ତି।

ଅନ୍ତିମ ଗେଟ୍ Devin ନେଟୱର୍କ ଅଡିଟ୍କୁ ମଧ୍ୟ ଯାଞ୍ଚ କରେ ଏବଂ Claude ଇଗ୍ରେସ୍ ଅଡିଟ୍ ଖାଲି ରହିବା ଆବଶ୍ୟକ କରେ।

## ପିନ୍ କରାଯାଇଥିବା ଟୁଲ୍ଗୁଡ଼ିକୁ ଅଦ୍ୟତନ କରିବା

ଇମେଜ୍ଟି `docker/devin-bridge/Dockerfile` ରେ Node, Claude Code ଏବଂ Devin CLI କୁ ପିନ୍ କରେ। ଅଦ୍ୟତନ କରିବା ପାଇଁ:

1. ସ୍ପଷ୍ଟ ଭାବରେ ଉଲ୍ଲେଖିତ ସଂସ୍କରଣଗୁଡ଼ିକୁ ପରିବର୍ତ୍ତନ କରନ୍ତୁ;
2. ଉଭୟ ଆର୍କିଟେକ୍ଚର୍-ନିର୍ଦ୍ଦିଷ୍ଟ Devin ଆର୍କାଇଭ୍ ଚେକ୍ସମ୍କୁ ଅଫିସିଆଲ୍
   ଆର୍ଟିଫ୍ୟାକ୍ଟର ମୂଲ୍ୟଗୁଡ଼ିକ ସହିତ ବଦଳାନ୍ତୁ;
3. ପୁନଃ ବିଲ୍ଡ କରନ୍ତୁ ଏବଂ ପ୍ରତ୍ୟେକ ଅଫ୍ଲାଇନ୍ ବୈଧତା ଯାଞ୍ଚ କମାଣ୍ଡ ଚଲାନ୍ତୁ;
4. ଇମେଜ୍ ଭିତରେ ସଂସ୍କରଣଗୁଡ଼ିକୁ ନିଶ୍ଚିତ କରନ୍ତୁ;
5. ପ୍ରମାଣିତ ତିନି-ପରିଦୃଶ୍ୟ ବିଶିଷ୍ଟ ଲାଇଭ୍ ସୁଇଟ୍କୁ ପୁଣି ଚଲାନ୍ତୁ।

ହୋଷ୍ଟରେ କୌଣସି CLI କୁ ଗ୍ଲୋବାଲ୍ ଭାବେ ଇନ୍ଷ୍ଟଲ୍ କରନ୍ତୁ ନାହିଁ କିମ୍ବା ଚେକ୍ସମ୍ ଯାଞ୍ଚକୁ
ଏକ ଅଯାଞ୍ଚିତ ଡାଉନ୍ଲୋଡ୍ ସହିତ ବଦଳାନ୍ତୁ ନାହିଁ।
