`devin-cli-agentic` omogoča, da dejansko izvajalno okolje Claude Code uporablja lokalno končno točko Anthropic
Messages storitve OmniRoute, medtem ko uradni Devin CLI zagotavlja odzive modela prek ACP stdio. Ne
spreminja obstoječih ponudnikov Anthropic, Claude OAuth, Claude Web ali `devin-cli`.

Za klice orodij, ki jih upravlja odjemalec, usmerjajte prek `devin-cli-agentic` (vzdevek `dva`),
ponudnika s podporo za orodja v obliki Claude. Podedovani izvajalnik ACP `devin-cli` (`dv`) podpira
samo besedilo: izvaja Devinov povzemalnik brez orodij in ne more vračati klicev orodij. Njegovi
metapodatki modela so ustrezno označeni, zato se mu kombinirano usmerjanje, ki zahteva orodja, izogne.

> **Trenutno stanje: pripeta različica Claude Code `2.1.258`; preverjanje brez povezave in v živo je bilo nazadnje zabeleženo
> pri različici `2.1.220`.** Pripeta različica `2.1.220` je uspešno dokončala tri izolirane scenarije prek Devin CLI
> `3000.2.17` in modela `swe-1-7-lightning`; ta končni preizkus v živo je potrdil korake `Read`,
> `Edit` in `Bash`, ki jih upravlja odjemalec, uspešne rezultate `npm test`, odkrivanje projektnih ukazov in
> veščin, usmerjanje izključno prek Devina ter ničelni izhodni promet do storitve Claude. Pripeta različica je bila nato posodobljena na `2.1.258`
> (generacijo CLI, ki jo posnema identiteta Claude storitve OmniRoute, in prvo različico, ki izvorno vključuje
> raven Fable 5.1). Pri novi pripeti različici sta bila na pripeti osnovni sliki preverjena namestitvena plast in
> `claude --version`, uspešno pa se izvedejo tudi zbirka enotskih preizkusov mostu, `compose config` in
> statični dokaz izolacije — vendar scenarij z lažnim okoljem brez povezave in zbirka treh scenarijev
> v živo še nista bila ponovno izvedena. Pred uporabo mostu s to pripeto različico ju ponovno izvedite
> (glejte »Posodabljanje pripetih orodij«).

## Arhitektura

```text
Claude Code 2.1.258 (izoliran vsebnik Linux brez korenskih pravic)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (oblika Claude, ponudnik brez preverjanja pristnosti)
  -> devin acp --agent-type summarizer (uradni ACP stdio, brez Devinovih orodij)
  -> račun Devin v namenskem nosilcu devin-auth
```

Privzeti agent ACP uradnega vmesnika CLI lahko izvaja lastna orodja, zato ga ta most ne
uporablja. Zažene fiksnega agenta ACP `summarizer`, katerega uradni način CLI nima orodij, in
serializirano zahtevo Anthropic oblikuje kot sled izvajanja. Ko je potrebno drugo dejanje, ki ga upravlja
Claude, mora odziv vsebovati natanko eno ovojnico odjemalskega orodja. Vsak ACP
`tool_call` ali `tool_call_update` je zavrnjen, preden je odziv mogoče označiti kot
uspešen.

Serializator v `open-sse/executors/devin-agentic/serializer.ts` ohrani `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice` in
orodja, ki jih zagotovi Claude Code. Slike in neznani bloki povzročijo izrecno napako. Veliki rezultati orodij
uporabljajo vidno oznako krajšanja.

Razčlenjevalnik sprejme eno samostojno ovojnico `<tool>{...}</tool>` na korak modela. Preveri
ime glede na seznam orodij v zahtevi, potrdi argumente glede na JSON Schema tega orodja,
zavrne mešanico pripovednega besedila in dejanj ter dovoli en omejen poskus popravila. Claude Code nato
lokalno izvede nastali Anthropic `tool_use` in pošlje `tool_result` nazaj prek
storitve OmniRoute.

## Samodejno usmerjanje

Ponudnik je upravičen do vključitve v nabore kandidatov `auto/*` storitve OmniRoute, kadar ni blokiran.
Upravičenost kandidata ne zagotavlja izbire: strategija usmerjanja kombinacije (na primer
zadnji znani delujoči ponudnik) lahko da prednost drugemu ponudniku. Uporabite `dva/<model>` ali kombinacijo s
prednostjo za Devin, kadar zahtevate, da je vsaka zahteva usmerjena prek Devina.

## Izolacija in model groženj

Namestitev, račun in konfiguracija Claude na gostitelju niso predmet obravnave in se štejejo za
prepovedane. Storitve Compose:

- se izvajajo kot UID/GID `10001:10001`, s korenskim datotečnim sistemom samo za branje, opuščenimi zmožnostmi in
  `no-new-privileges`;
- uporabljajo zasebni `/home/bridge`, namenski nosilec za konfiguracijo Claude, izolirane podatke OmniRoute
  in ločen nosilec `devin-auth`;
- priklapljajo samo začasne delovne prostore/dokazila `.sandbox`;
- ne priklapljajo domačega imenika gostitelja, Keychain, poverilnic SSH, poverilnic za oblak ali vtičnice Docker;
- sestavijo eksplicitna okolja ter odstranijo spremenljivke API/OAuth/usmerjanja Anthropic;
- usmerjajo sklepanje Claude Code samo na `http://omniroute:20128` z zgolj lokalnim ključem.

Profil brez povezave uporablja notranje omrežje. V profilu z dostopom do omrežja OmniRoute doseže
uradne končne točke Devin samo prek `network-guard`; nepovezani cilji so zavrnjeni.
Claude Code ima ločeno zaščito izhodnega prometa, ki zavrača vse povezave, in lahko prek `NO_PROXY` doseže samo lokalno
storitev OmniRoute. Revizijske datoteke zaščit so priklopljene samo v njihovem procesu zaščite. Skripti
preverijo lastništvo datotek, način, število povezav in vsako odločitev, preden izvozijo
dokazila brez žetonov.

Dokaz izolacije zaženite neodvisno:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

Preveri topologijo, poimenovane priklope, nastavitve izvajanja brez korenskih pravic in samo za branje, eksplicitno lokalno usmerjanje,
odsotnost občutljivih spremenljivk okolja, odsotnost vtičnice Docker, blokiran dostop do
`api.anthropic.com` in `claude.ai`, izbiro ponudnika izključno Devin ter eksplicitno napako, kadar
zaledni sistem ACP ni na voljo.

## Prva nastavitev in običajna uporaba

Zgradite pripeto sliko:

```bash
./scripts/devin-bridge/build
```

Overite samo izolirani nosilec Devin:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

Ukaz za prijavo uporablja uradni ročni postopek z žetonom, namenjen oddaljenim/vsebniškim
okoljem. Vrednost se vnese neposredno v poziv CLI; ni podana kot
argument procesa, zapisana v Git ali kopirana z gostitelja.

Zaženite izolirano izvajalno okolje Claude Code:

```bash
./scripts/devin-bridge/launch
```

`launch` pred zagonom
Claude Code v vsebniku znova preveri izolacijo, overjanje Devin in odkrivanje modelov. Nikoli ne zažene gostiteljeve izvršne datoteke Claude. Vzdevke modelov je mogoče
nastaviti v `.env.devin-bridge`; vsaka konfigurirana vrednost mora ohraniti predpono
`devin-cli-agentic/`.

## Ukazi za preverjanje

Ponovljiva pot brez povezave ne zahteva računa Devin in med izvajanjem nima dostopa do interneta:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

Izbirna overjena pot z dostopom do omrežja je:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

Izvajalnik testov z dostopom do omrežja med scenariji počaka, da prepreči sunkovito odpiranje sej ACP, in
preverja strukturirane dogodke toka Claude, namesto da bi zaupal besedilnim trditvam. Njegovi trije
scenariji dokazujejo:

1. neposredno branje projekta in analizo napak;
2. dejanski `Edit`, odjemalčevo izvajanje `Bash` `npm test` in končni rezultat;
3. `/bridge-check` skupaj z odkrivanjem `bridge-proof`, branjem projekta, še enim uspešnim
   odjemalčevim izvajanjem `npm test` in dokončanjem brez čakajočega dela.

Končna kontrola preveri tudi revizijo omrežja Devin in zahteva, da revizija izhodnega prometa Claude
ostane prazna.

## Posodabljanje pripetih orodij

Slika pripne različice Node, Claude Code in Devin CLI v datoteki
`docker/devin-bridge/Dockerfile`. Za posodobitev:

1. spremenite izrecno navedene različice;
2. zamenjajte kontrolni vsoti arhivov Devin za obe arhitekturi z vrednostmi za uradni
   artefakt;
3. znova zgradite sliko in zaženite vse ukaze za preverjanje brez povezave;
4. potrdite različice znotraj slike;
5. znova zaženite overjeno živo zbirko treh scenarijev.

Nobenega od vmesnikov CLI ne nameščajte globalno na gostiteljski sistem in preverjanja kontrolne vsote ne nadomeščajte z
nepreverjenim prenosom.

## Diagnostika in čiščenje

- `docker compose -f docker/devin-bridge/compose.yml --profile offline logs omniroute`
  prikazuje lokalno usmerjanje in očiščene napake izvajalnika.
- `.sandbox/evidence/mock-acp.jsonl` beleži deterministična lažna dejanja ACP.
- `.sandbox/evidence/claude-stream.jsonl` beleži dejanski zagon Claude Code brez povezave.
- `.sandbox/evidence/live-*.jsonl` beleži tri preverjene žive tokove.
- `.sandbox/evidence/egress.jsonl` in `.sandbox/evidence/claude-egress.jsonl` sta preverjeni
  kopiji revizij varovala brez žetonov.

Ustavite pripadajoče vsebnike in omrežja, pri tem pa ohranite nosilce za prijavo in konfiguracijo:

```bash
./scripts/devin-bridge/clean
```

Odstranite celotno okolje, ki pripada mostu, vključno z imenovanimi nosilci:

```bash
./scripts/devin-bridge/clean --all
```

## Omejitve

- Most uporablja nespremenljivo vlogo `summarizer` brez orodij, ker Devin CLI `3000.2.17`
  ne ponuja nevtralnega agenta ACP brez orodij. Vmesnik kompenzira vmesne odgovore v obliki
  povzetkov, vendar je lahko en omejen poskus popravila še vedno izrecno neuspešen.
- Živi klici ACP lahko vrnejo prehodne odzive `502`/`504`. Ogrodje razmakne scenarije;
  trajna napaka ostane varno zaprta in nikoli ne izbere drugega ponudnika.
- Kontekst ACP se znova ustvari iz vsake zahteve Anthropic; vezanosti na proces/sejo
  ni.
- Podprt je en klic orodja na odziv modela; vzporedni klici so zavrnjeni.
- Slike izrecno niso podprte. Zmogljivosti vida, izpis razmišljanja, nadzor vloženega napora in kontekstno
  okno velikosti 1M niso oglaševani.
- SSE uporablja veljavne dogodke življenjskega cikla Anthropic, vendar se odda šele po tem, ko je zbran
  omejeni obrat ACP; kosi ACP se ne posredujejo sproti.
