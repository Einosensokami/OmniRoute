`devin-cli-agentic`, ഔദ്യോഗിക Devin CLI മോഡൽ പ്രതികരണങ്ങൾ ACP stdio വഴി നൽകുമ്പോൾ, യഥാർത്ഥ Claude Code റൺടൈമിന് OmniRoute-ന്റെ ലോക്കൽ Anthropic Messages എൻഡ്പോയിന്റ് ഉപയോഗിക്കാൻ അനുവദിക്കുന്നു. നിലവിലുള്ള Anthropic, Claude OAuth, Claude Web, അല്ലെങ്കിൽ `devin-cli` പ്രൊവൈഡറുകളിൽ ഇത് മാറ്റം വരുത്തുന്നില്ല.

ക്ലയന്റ് നിയന്ത്രിക്കുന്ന ടൂൾ കോളുകൾക്കായി, Claude-ഫോർമാറ്റിലുള്ള ടൂൾ-പിന്തുണയുള്ള പ്രൊവൈഡറായ `devin-cli-agentic` (അപരനാമം `dva`) വഴി റൂട്ട് ചെയ്യുക. പഴയ `devin-cli` (`dv`) ACP എക്സിക്യൂട്ടർ ടെക്സ്റ്റ്-മാത്രമാണ്: അത് Devin-ന്റെ ടൂളുകളില്ലാത്ത സമ്മറൈസർ പ്രവർത്തിപ്പിക്കുന്നു, അതിനാൽ ടൂൾ കോളുകൾ തിരികെ നൽകാൻ കഴിയില്ല. ടൂൾ ആവശ്യമായ കോംബോ റൂട്ടിംഗ് അതിനെ ഒഴിവാക്കുന്നതിനായി അതിന്റെ മോഡൽ മെറ്റാഡാറ്റ അതനുസരിച്ച് അടയാളപ്പെടുത്തിയിരിക്കുന്നു.

> **നിലവിലെ സ്ഥിതി: Claude Code `2.1.258`-ലേക്ക് പിൻ ചെയ്തിരിക്കുന്നു; ഓഫ്ലൈൻ, ലൈവ് വാലിഡേഷൻ അവസാനമായി രേഖപ്പെടുത്തിയത്
> `2.1.220`-ലാണ്.** `2.1.220` പിൻ, Devin CLI `3000.2.17`, മോഡൽ `swe-1-7-lightning` എന്നിവയിലൂടെ മൂന്ന് ഒറ്റപ്പെടുത്തിയ സാഹചര്യങ്ങൾ പൂർത്തിയാക്കി; ആ അന്തിമ ലൈവ് റൺ ക്ലയന്റ് നിയന്ത്രിക്കുന്ന `Read`,
> `Edit`, `Bash` ടേണുകൾ, വിജയകരമായ `npm test` ഫലങ്ങൾ, പ്രോജക്റ്റ് കമാൻഡിന്റെയും സ്കില്ലിന്റെയും
> കണ്ടെത്തൽ, Devin-മാത്രം റൂട്ടിംഗ്, Claude-ലേക്കുള്ള പൂജ്യം എഗ്രസ് എന്നിവ തെളിയിച്ചു. തുടർന്ന് പിൻ `2.1.258`-ലേക്ക്
> ഉയർത്തി (OmniRoute-ന്റെ Claude ഐഡന്റിറ്റി ആൾമാറാട്ടം നടത്തുന്ന CLI തലമുറയും Fable 5.1 ടയർ
> നേറ്റീവായി ഉൾപ്പെടുത്തുന്ന ആദ്യ ലൈനും ഇതാണ്). പുതിയ പിന്നിൽ, പിൻ ചെയ്ത ബേസ് ഇമേജിൽ ഇൻസ്റ്റാൾ ലെയറും `claude --version`-ഉം
> പരിശോധിച്ചു; കൂടാതെ ബ്രിഡ്ജ് യൂണിറ്റ് സ്യൂട്ട്, `compose config`, സ്റ്റാറ്റിക് ഐസൊലേഷൻ പ്രൂഫ് എന്നിവ
> വിജയിക്കുന്നു — എന്നാൽ ഓഫ്ലൈൻ മോക്ക് സാഹചര്യവും ലൈവ് മൂന്ന്-സാഹചര്യ സ്യൂട്ടും
> ഇതുവരെ വീണ്ടും പ്രവർത്തിപ്പിച്ചിട്ടില്ല. ഈ പിന്നിനൊപ്പം ബ്രിഡ്ജിനെ ആശ്രയിക്കുന്നതിന് മുമ്പ് അവ വീണ്ടും പ്രവർത്തിപ്പിക്കുക ("Updating pinned tools" കാണുക).

## ആർക്കിടെക്ചർ

```text
Claude Code 2.1.258 (ഒറ്റപ്പെടുത്തിയ നോൺ-റൂട്ട് Linux കണ്ടെയ്നർ)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (Claude-ഫോർമാറ്റ്, ഓതന്റിക്കേഷൻ ആവശ്യമില്ലാത്ത പ്രൊവൈഡർ)
  -> devin acp --agent-type summarizer (ഔദ്യോഗിക ACP stdio, Devin ടൂളുകളില്ല)
  -> സമർപ്പിത devin-auth വോളിയത്തിലുള്ള Devin അക്കൗണ്ട്
```

ഔദ്യോഗിക CLI-യുടെ ഡിഫോൾട്ട് ACP ഏജന്റിന് സ്വന്തം ടൂളുകൾ പ്രവർത്തിപ്പിക്കാൻ കഴിയുന്നതിനാൽ, ഈ ബ്രിഡ്ജ് അത് ഉപയോഗിക്കുന്നില്ല. ടൂളുകളില്ലാത്ത ഔദ്യോഗിക CLI മോഡിലുള്ള സ്ഥിരമായ `summarizer` ACP ഏജന്റിനെ ഇത് ആരംഭിക്കുകയും സീരിയലൈസ് ചെയ്ത Anthropic അഭ്യർത്ഥനയെ ഒരു എക്സിക്യൂഷൻ ട്രേസായി ഫ്രെയിം ചെയ്യുകയും ചെയ്യുന്നു. Claude നിയന്ത്രിക്കുന്ന മറ്റൊരു പ്രവർത്തനം ആവശ്യമായി വരുമ്പോൾ, പ്രതികരണത്തിൽ കൃത്യമായി ഒരു ക്ലയന്റ് ടൂൾ എൻവലപ്പ് ഉണ്ടായിരിക്കണം. ഒരു പ്രതികരണം വിജയകരമാണെന്ന് റിപ്പോർട്ട് ചെയ്യുന്നതിന് മുമ്പ് ഏതൊരു ACP `tool_call` അല്ലെങ്കിൽ `tool_call_update`-ഉം നിരസിക്കപ്പെടും.

`open-sse/executors/devin-agentic/serializer.ts`-ലെ സീരിയലൈസർ, `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice`, കൂടാതെ
Claude Code നൽകുന്ന ടൂളുകൾ എന്നിവ അതേപടി നിലനിർത്തുന്നു. ഇമേജുകളും തിരിച്ചറിയാത്ത ബ്ലോക്കുകളും വ്യക്തമായി പരാജയപ്പെടുന്നു. വലിയ ടൂൾ ഫലങ്ങൾ ദൃശ്യമാകുന്ന ഒരു ട്രങ്കേഷൻ മാർക്കർ ഉപയോഗിക്കുന്നു.

ഒരു മോഡൽ ടേണിൽ ഒറ്റയ്ക്ക് നിലകൊള്ളുന്ന ഒരു `<tool>{...}</tool>` എൻവലപ്പ് പാർസർ സ്വീകരിക്കുന്നു. അത്
അഭ്യർത്ഥനയിലെ ടൂൾ ലിസ്റ്റുമായി പേര് പരിശോധിക്കുകയും, ആ ടൂളിന്റെ JSON Schema-യ്ക്കെതിരെ ആർഗ്യുമെന്റുകൾ സാധൂകരിക്കുകയും, വിവരണവും പ്രവർത്തനങ്ങളും കലർത്തുന്നത് നിരസിക്കുകയും, പരിധിയുള്ള ഒരു റിപ്പയർ അനുവദിക്കുകയും ചെയ്യുന്നു. തുടർന്ന് Claude Code ലഭിക്കുന്ന Anthropic `tool_use` ലോക്കലായി പ്രവർത്തിപ്പിക്കുകയും `tool_result` OmniRoute വഴി തിരികെ അയയ്ക്കുകയും ചെയ്യുന്നു.

## ഓട്ടോ-റൂട്ടിംഗ്

ബ്ലോക്ക് ചെയ്തിട്ടില്ലെങ്കിൽ, OmniRoute-ന്റെ `auto/*` കാൻഡിഡേറ്റ് പൂളുകളിൽ ഉൾപ്പെടാൻ ഈ പ്രൊവൈഡർ യോഗ്യമാണ്.
കാൻഡിഡേറ്റ് യോഗ്യത തിരഞ്ഞെടുപ്പ് ഉറപ്പാക്കുന്നില്ല: കോംബോയുടെ റൂട്ടിംഗ് സ്ട്രാറ്റജി (ഉദാഹരണത്തിന്,
അവസാനം വിജയകരമായത്) മറ്റൊരു പ്രൊവൈഡറിന് മുൻഗണന നൽകിയേക്കാം. എല്ലാ അഭ്യർത്ഥനകളും Devin വഴി പോകണമെന്ന്
നിർബന്ധമാണെങ്കിൽ `dva/<model>` അല്ലെങ്കിൽ Devin-ന് മുൻഗണന നൽകുന്ന ഒരു കോംബോ ഉപയോഗിക്കുക.

## ഒറ്റപ്പെടുത്തലും ഭീഷണി മാതൃകയും

ഹോസ്റ്റിലെ Claude ഇൻസ്റ്റാളേഷൻ, അക്കൗണ്ട്, കോൺഫിഗറേഷൻ എന്നിവ പരിധിക്കു പുറത്തുള്ളവയും
ഉപയോഗിക്കാൻ പാടില്ലാത്തവയുമായി കണക്കാക്കുന്നു. Compose സേവനങ്ങൾ:

- UID/GID `10001:10001` ആയി, വായിക്കാൻ മാത്രം കഴിയുന്ന റൂട്ട് ഫയൽസിസ്റ്റം, നീക്കംചെയ്ത capabilities,
  `no-new-privileges` എന്നിവയോടെ പ്രവർത്തിക്കുന്നു;
- സ്വകാര്യ `/home/bridge`, സമർപ്പിത Claude കോൺഫിഗറേഷൻ volume, ഒറ്റപ്പെടുത്തിയ OmniRoute ഡാറ്റ,
  പ്രത്യേക `devin-auth` volume എന്നിവ ഉപയോഗിക്കുന്നു;
- ഉപേക്ഷിക്കാവുന്ന `.sandbox` workspaces/evidence മാത്രം mount ചെയ്യുന്നു;
- ഹോസ്റ്റ് home, Keychain, SSH, cloud credentials, അല്ലെങ്കിൽ Docker socket എന്നിവ mount ചെയ്യുന്നില്ല;
- വ്യക്തമായ environments നിർമ്മിക്കുകയും Anthropic API/OAuth/routing variables നീക്കംചെയ്യുകയും ചെയ്യുന്നു;
- പ്രാദേശികമായി മാത്രം ഉപയോഗിക്കാവുന്ന key ഉപയോഗിച്ച് Claude Code inference-നെ
  `http://omniroute:20128` എന്നതിലേക്ക് മാത്രം നയിക്കുന്നു.

ഓഫ്ലൈൻ പ്രൊഫൈൽ ഒരു ആന്തരിക നെറ്റ്വർക്ക് ഉപയോഗിക്കുന്നു. ലൈവ് പ്രൊഫൈലിൽ, OmniRoute ഔദ്യോഗിക
Devin endpoints-ലേക്ക് `network-guard` വഴി മാത്രമേ എത്തുകയുള്ളൂ; ബന്ധമില്ലാത്ത destinations
നിരസിക്കപ്പെടുന്നു. Claude Code-ന് പ്രത്യേകം എല്ലാ egress-ഉം നിരസിക്കുന്ന guard ഉണ്ട്, കൂടാതെ
`NO_PROXY` വഴി പ്രാദേശിക OmniRoute സേവനത്തിലേക്ക് മാത്രമേ എത്താൻ കഴിയൂ. Guard audit files
അവയുടെ guard process മാത്രം mount ചെയ്യുന്നു. Token-രഹിത evidence export ചെയ്യുന്നതിനുമുമ്പ്
scripts ഫയലിന്റെ ownership, mode, link count, കൂടാതെ ഓരോ തീരുമാനവും പരിശോധിക്കുന്നു.

ഒറ്റപ്പെടുത്തൽ തെളിവ് സ്വതന്ത്രമായി പ്രവർത്തിപ്പിക്കുക:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

ഇത് topology, named mounts, non-root/read-only settings, വ്യക്തമായ local routing,
സെൻസിറ്റീവ് environment variables-ന്റെ അഭാവം, Docker socket-ന്റെ അഭാവം,
`api.anthropic.com`, `claude.ai` എന്നിവയിലേക്കുള്ള തടയപ്പെട്ട access, Devin-മാത്രമുള്ള provider
selection, ACP backend ലഭ്യമല്ലാത്തപ്പോൾ വ്യക്തമായ failure എന്നിവ സാധൂകരിക്കുന്നു.

## ആദ്യതവണത്തെ സജ്ജീകരണവും സാധാരണ ഉപയോഗവും

പിൻ ചെയ്ത image build ചെയ്യുക:

```bash
./scripts/devin-bridge/build
```

ഒറ്റപ്പെടുത്തിയ Devin volume മാത്രം authenticate ചെയ്യുക:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

Login command വിദൂര/container environments-നായി ഉദ്ദേശിച്ചിട്ടുള്ള ഔദ്യോഗിക manual-token flow
ഉപയോഗിക്കുന്നു. മൂല്യം CLI prompt-ലേക്ക് നേരിട്ട് നൽകുന്നു; അത് process argument ആയി
നൽകുകയോ, Git-ലേക്ക് എഴുതുകയോ, ഹോസ്റ്റിൽനിന്ന് പകർത്തുകയോ ചെയ്യുന്നില്ല.

ഒറ്റപ്പെടുത്തിയ Claude Code runtime ആരംഭിക്കുക:

```bash
./scripts/devin-bridge/launch
```

Containerized Claude Code ആരംഭിക്കുന്നതിനുമുമ്പ് `launch` isolation, Devin authentication,
model discovery എന്നിവ വീണ്ടും പരിശോധിക്കുന്നു. ഇത് ഒരിക്കലും ഹോസ്റ്റിലെ Claude executable
പ്രവർത്തിപ്പിക്കില്ല. Model aliases `.env.devin-bridge`-ൽ സജ്ജീകരിക്കാം; കോൺഫിഗർ ചെയ്ത ഓരോ
മൂല്യവും `devin-cli-agentic/` prefix നിലനിർത്തണം.

## സാധൂകരണ commands

പുനരാവർത്തിക്കാവുന്ന ഓഫ്ലൈൻ പാതയ്ക്ക് Devin account ആവശ്യമില്ല, കൂടാതെ runtime Internet-ഉം ഇല്ല:

ACP sessions കൂട്ടത്തോടെ തുറക്കുന്നത് ഒഴിവാക്കാൻ live runner സാഹചര്യങ്ങൾക്കിടയിൽ കാത്തിരിക്കുകയും,
വാചകരൂപത്തിലുള്ള അവകാശവാദങ്ങൾ വിശ്വസിക്കുന്നതിനുപകരം ഘടനാബദ്ധമായ Claude stream events
സാധൂകരിക്കുകയും ചെയ്യുന്നു. അതിന്റെ മൂന്ന് സാഹചര്യങ്ങൾ ഇനിപ്പറയുന്നവ തെളിയിക്കുന്നു:

2. ഒരു യഥാർത്ഥ `Edit`, client-owned `Bash` `npm test`, ഒരു terminal result;
3. `/bridge-check`, `bridge-proof` discovery, project reads, വിജയകരമായ മറ്റൊരു
   client-owned `npm test`, pending work ഇല്ലാതെയുള്ള completion.

അന്തിമ gate Devin network audit-ഉം പരിശോധിക്കുകയും Claude egress audit ശൂന്യമായി
തുടരണമെന്ന് ആവശ്യപ്പെടുകയും ചെയ്യുന്നു.

## പിൻ ചെയ്ത ടൂളുകൾ അപ്ഡേറ്റ് ചെയ്യൽ

ഇമേജ് Node, Claude Code, Devin CLI എന്നിവയെ
`docker/devin-bridge/Dockerfile`-ൽ പിൻ ചെയ്യുന്നു. അപ്ഡേറ്റ് ചെയ്യാൻ:

1. വ്യക്തമായി നൽകിയിരിക്കുന്ന പതിപ്പുകൾ മാറ്റുക;
2. ഔദ്യോഗിക ആർട്ടിഫാക്റ്റിനുള്ള മൂല്യങ്ങൾ ഉപയോഗിച്ച് ആർക്കിടെക്ചർ-നിർദ്ദിഷ്ടമായ രണ്ട് Devin ആർക്കൈവ് ചെക്ക്സമ്മുകളും മാറ്റിസ്ഥാപിക്കുക;
3. വീണ്ടും ബിൽഡ് ചെയ്ത് എല്ലാ ഓഫ്ലൈൻ സാധൂകരണ കമാൻഡുകളും പ്രവർത്തിപ്പിക്കുക;
4. ഇമേജിനുള്ളിലെ പതിപ്പുകൾ സ്ഥിരീകരിക്കുക;
5. പ്രാമാണീകരിച്ച മൂന്ന്-സാഹചര്യ ലൈവ് സ്യൂട്ട് വീണ്ടും പ്രവർത്തിപ്പിക്കുക.

ഹോസ്റ്റിൽ ഏതെങ്കിലും CLI ആഗോളമായി ഇൻസ്റ്റാൾ ചെയ്യുകയോ ചെക്ക്സം പരിശോധനയ്ക്ക് പകരം
പരിശോധിക്കാത്ത ഡൗൺലോഡ് ഉപയോഗിക്കുകയോ ചെയ്യരുത്.
