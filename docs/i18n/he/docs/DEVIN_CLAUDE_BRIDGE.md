`devin-cli-agentic` מאפשר לסביבת זמן הריצה האמיתית של Claude Code להשתמש בנקודת הקצה המקומית של OmniRoute עבור Anthropic
Messages, בעוד שה-CLI הרשמי של Devin מספק תגובות מודל דרך ACP stdio. הוא
אינו משנה את הספקים הקיימים Anthropic, Claude OAuth, Claude Web או `devin-cli`.

עבור קריאות לכלים שבבעלות הלקוח, יש לנתב דרך `devin-cli-agentic` (כינוי `dva`),
הספק תומך-הכלים בפורמט Claude. מבצע ה-ACP הוותיק `devin-cli` (`dv`) הוא
טקסטואלי בלבד: הוא מפעיל את המסכם נטול-הכלים של Devin ואינו יכול להחזיר קריאות לכלים. המטא-נתונים של
המודל שלו מסומנים בהתאם, כך שניתוב משולב שדורש כלים יימנע ממנו.

> **מצב נוכחי: Claude Code מקובע לגרסה `2.1.258`; אימות לא מקוון ואימות חי תועדו לאחרונה
> בגרסה `2.1.220`.** הקיבוע לגרסה `2.1.220` השלים שלושה תרחישים מבודדים דרך Devin CLI
> `3000.2.17` והמודל `swe-1-7-lightning`; אותה הרצה חיה סופית הוכיחה תורות `Read`,
> `Edit` ו-`Bash` שבבעלות הלקוח, תוצאות מוצלחות של `npm test`, גילוי פקודות ומיומנויות
> של הפרויקט, ניתוב דרך Devin בלבד ואפס תעבורה יוצאת אל Claude. לאחר מכן הקיבוע הועלה לגרסה `2.1.258`
> (דור ה-CLI שאותו מתחזה זהות Claude של OmniRoute, והגרסה הראשונה שמספקת
> את שכבת Fable 5.1 באופן מובנה). עם הקיבוע החדש, שכבת ההתקנה ו-`claude --version`
> אומתו בתמונת הבסיס המקובעת, וחבילת בדיקות היחידה של הגשר, `compose config` וכן
> הוכחת הבידוד הסטטית עוברות — אך תרחיש ההדמיה הלא מקוון וחבילת שלושת התרחישים החיה
> טרם הורצו מחדש. יש להריץ אותם מחדש (ראו "עדכון כלים מקובעים") לפני שמסתמכים על
> הגשר עם קיבוע זה.

## ארכיטקטורה

```text
Claude Code 2.1.258 (קונטיינר Linux מבודד שאינו root)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (בפורמט Claude, ספק ללא אימות)
  -> devin acp --agent-type summarizer (ACP stdio רשמי, ללא כלי Devin)
  -> חשבון Devin באמצעי האחסון הייעודי devin-auth
```

סוכן ה-ACP שמוגדר כברירת מחדל ב-CLI הרשמי יכול להפעיל כלים משלו, ולכן גשר זה אינו משתמש
בו. הוא מפעיל את סוכן ה-ACP הקבוע `summarizer`, שמצב ה-CLI הרשמי שלו אינו כולל כלים, וממסגר
את בקשת Anthropic שעברה סריאליזציה כעקבת ביצוע. כאשר נדרשת פעולה נוספת שבבעלות Claude,
התגובה חייבת להכיל מעטפת אחת בדיוק של כלי לקוח. כל `tool_call` או `tool_call_update`
של ACP נדחים לפני שניתן לדווח על תגובה כמוצלחת.

הסריאלייזר ב-`open-sse/executors/devin-agentic/serializer.ts` משמר את `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice` ואת
הכלים שסופקו על ידי Claude Code. תמונות ובלוקים לא מוכרים נכשלים באופן מפורש. תוצאות גדולות
של כלים משתמשות בסמן קיטוע גלוי.

המנתח מקבל מעטפת עצמאית אחת מסוג `<tool>{...}</tool>` בכל תור של המודל. הוא בודק
את השם מול רשימת הכלים שבבקשה, מאמת ארגומנטים מול JSON Schema של אותו כלי,
דוחה שילוב של טקסט נרטיבי ופעולות ומתיר ניסיון תיקון תחום אחד. לאחר מכן Claude Code
מפעיל מקומית את `tool_use` שנוצר בפורמט Anthropic ושולח את `tool_result` בחזרה דרך
OmniRoute.

## ניתוב אוטומטי

הספק כשיר להשתתף במאגרי המועמדים `auto/*` של OmniRoute כאשר הוא אינו חסום.
כשירות כמועמד אינה מבטיחה בחירה: אסטרטגיית הניתוב של השילוב (לדוגמה,
האחרון שנודע כתקין) עשויה להעדיף ספק אחר. השתמשו ב-`dva/<model>` או בשילוב שמעניק
עדיפות ל-Devin כאשר נדרש שכל בקשה תעבור דרך Devin.

## בידוד ומודל איומים

התקנת Claude, החשבון והתצורה במארח אינם בתחום האחריות ונחשבים
לאסורים. שירותי Compose:

- פועלים תחת UID/GID‏ `10001:10001`, עם מערכת קבצים שורשית לקריאה בלבד, יכולות שהוסרו ו-
  `no-new-privileges`;
- משתמשים ב-`/home/bridge` פרטי, אמצעי אחסון ייעודי לתצורת Claude, נתוני OmniRoute מבודדים
  ואמצעי אחסון נפרד של `devin-auth`;
- מעגנים רק מרחבי עבודה/ראיות זמניים מסוג `.sandbox`;
- אינם מעגנים את תיקיית הבית של המארח, Keychain, אישורי SSH, אישורי ענן או את שקע Docker;
- בונים סביבות מפורשות ומסירים משתני API/OAuth/ניתוב של Anthropic;
- מנתבים את ההיסק של Claude Code רק אל `http://omniroute:20128` באמצעות מפתח מקומי בלבד.

הפרופיל הלא־מקוון משתמש ברשת פנימית. בפרופיל הפעיל, OmniRoute ניגש אל
נקודות הקצה הרשמיות של Devin רק דרך `network-guard`; יעדים שאינם קשורים נחסמים.
ל-Claude Code יש מנגנון נפרד לחסימת כל תעבורת היציאה, והוא יכול לגשת רק לשירות OmniRoute
המקומי דרך `NO_PROXY`. קובצי הביקורת של מנגנוני ההגנה מעוגנים רק בתהליך ההגנה המתאים להם.
הסקריפטים מאמתים בעלות על קבצים, מצב, מספר קישורים וכל החלטה לפני ייצוא
ראיות נטולות אסימונים.

הריצו את הוכחת הבידוד באופן עצמאי:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

היא מאמתת את הטופולוגיה, עיגונים בעלי שם, הגדרות של משתמש שאינו root/קריאה בלבד, ניתוב מקומי מפורש,
היעדר משתני סביבה רגישים, היעדר שקע Docker, חסימת גישה אל
`api.anthropic.com` ו-`claude.ai`, בחירה בספק Devin בלבד וכשל מפורש כאשר
הקצה האחורי של ACP אינו זמין.

## הגדרה ראשונית ושימוש רגיל

בנו את התמונה המקובעת:

```bash
./scripts/devin-bridge/build
```

בצעו אימות רק מול אמצעי האחסון המבודד של Devin:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

פקודת ההתחברות משתמשת בתהליך הרשמי של אסימון ידני, המיועד לסביבות מרוחקות/קונטיינרים.
הערך מוזן ישירות בשורת הקלט של ה-CLI; הוא אינו מועבר כארגומנט לתהליך,
נכתב ל-Git או מועתק מהמארח.

הפעילו את סביבת זמן הריצה המבודדת של Claude Code:

```bash
./scripts/devin-bridge/launch
```

`launch` בודק מחדש את הבידוד, אימות Devin וגילוי המודלים לפני הפעלת
Claude Code בתוך קונטיינר. הוא לעולם אינו מריץ את קובץ ההפעלה של Claude מהמארח. ניתן
להגדיר כינויים למודלים ב-`.env.devin-bridge`; כל ערך מוגדר חייב לשמור על התחילית
`devin-cli-agentic/`.

## פקודות אימות

המסלול הלא־מקוון הניתן לשחזור אינו דורש חשבון Devin ואין לו גישה לאינטרנט בזמן ריצה:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

המסלול הפעיל המאומת, המחייב הסכמה מפורשת, הוא:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

מריץ הבדיקות הפעילות ממתין בין תרחישים כדי להימנע מפתיחת הפעלות ACP בפרץ,
ומאמת אירועי זרם מובנים של Claude במקום להסתמך על טענות טקסטואליות. שלושת
התרחישים שלו מוכיחים:

1. קריאה ישירה מהפרויקט וניתוח ליקויים;
2. פעולת `Edit` אמיתית, הרצת `Bash` מסוג `npm test` בבעלות הלקוח ותוצאת מסוף;
3. גילוי `/bridge-check` יחד עם `bridge-proof`, קריאות מהפרויקט, הרצה מוצלחת נוספת
   של `npm test` בבעלות הלקוח והשלמה ללא עבודה ממתינה.

השער הסופי בודק גם את ביקורת הרשת של Devin ודורש שביקורת תעבורת היציאה של Claude
תישאר ריקה.

## עדכון כלים מקובעים

ה-image מקבע את Node, Claude Code ו-Devin CLI בתוך
`docker/devin-bridge/Dockerfile`. כדי לעדכן:

1. שנו את הגרסאות המפורשות;
2. החליפו את שני סיכומי הביקורת של ארכיוני Devin הספציפיים לארכיטקטורה בערכים של הארטיפקט
   הרשמי;
3. בנו מחדש והריצו כל פקודת אימות לא מקוונת;
4. ודאו את הגרסאות בתוך ה-image;
5. הריצו מחדש את חבילת הבדיקות החיה והמאומתת הכוללת שלושה תרחישים.

אין להתקין אף אחד משני ממשקי שורת הפקודה באופן גלובלי במארח, ואין להחליף את אימות סיכום הביקורת
בהורדה לא מאומתת.

## אבחון וניקוי

- `docker compose -f docker/devin-bridge/compose.yml --profile offline logs omniroute`
  מציג ניתוב מקומי ושגיאות executor שעברו טיוב.
- `.sandbox/evidence/mock-acp.jsonl` מתעד פעולות ACP מדומות ודטרמיניסטיות.
- `.sandbox/evidence/claude-stream.jsonl` מתעד את ההרצה הלא מקוונת האמיתית של Claude Code.
- `.sandbox/evidence/live-*.jsonl` מתעד את שלושת הזרמים החיים שאומתו.
- `.sandbox/evidence/egress.jsonl` ו-`.sandbox/evidence/claude-egress.jsonl` הם עותקים מאומתים
  וללא אסימונים של ביקורות מנגנון ההגנה.

עצרו קונטיינרים ורשתות בבעלות הסביבה תוך שמירה על אמצעי האחסון של ההתחברות והתצורה:

```bash
./scripts/devin-bridge/clean
```

הסירו את הסביבה המלאה שבבעלות הגשר, לרבות אמצעי אחסון בעלי שם:

```bash
./scripts/devin-bridge/clean --all
```

## מגבלות

- הגשר מסתמך על תפקיד `summarizer` המקובע וללא כלים, משום ש-Devin CLI `3000.2.17`
  אינו חושף סוכן ACP ניטרלי ללא כלים. המתאם מפצה על תגובות ביניים בצורת סיכום,
  אך ניסיון תיקון מוגבל יחיד עדיין עלול להיכשל באופן מפורש.
- קריאות ACP חיות עשויות להחזיר תגובות `502`/`504` זמניות. רתמת הבדיקה מרווחת בין התרחישים;
  כשל מתמשך נשאר במצב כשל סגור ולעולם אינו בוחר ספק אחר.
- ההקשר של ACP נבנה מחדש מכל בקשת Anthropic; אין זיקה לתהליך או להפעלה.
- נתמכת קריאת כלי אחת לכל תגובת מודל; קריאות מקבילות נדחות.
- תמונות אינן נתמכות במפורש. יכולות ראייה, פלט חשיבה, בקרות מאמץ וחלון הקשר של 1M
  אינם מוצגים כנתמכים.
- SSE משתמש באירועי מחזור חיים תקינים של Anthropic, אך נפלט לאחר איסוף תור ה-ACP המוגבל;
  מקטעי ACP אינם מועברים באופן מצטבר.
