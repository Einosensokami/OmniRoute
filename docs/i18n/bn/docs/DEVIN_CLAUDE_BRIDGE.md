`devin-cli-agentic` প্রকৃত Claude Code রানটাইমকে OmniRoute-এর স্থানীয় Anthropic
Messages এন্ডপয়েন্ট ব্যবহার করতে দেয়, যেখানে অফিসিয়াল Devin CLI ACP stdio-এর মাধ্যমে মডেল প্রতিক্রিয়া সরবরাহ করে। এটি
বিদ্যমান Anthropic, Claude OAuth, Claude Web, বা `devin-cli` প্রোভাইডারগুলো পরিবর্তন করে না।

ক্লায়েন্ট-মালিকানাধীন টুল কলের জন্য, Claude-ফরম্যাটের টুল-সক্ষম প্রোভাইডার
`devin-cli-agentic` (উপনাম `dva`)-এর মাধ্যমে রাউট করুন। লিগ্যাসি `devin-cli` (`dv`) ACP এক্সিকিউটরটি
শুধুমাত্র টেক্সট সমর্থন করে: এটি Devin-এর টুলবিহীন সামারাইজার চালায় এবং টুল কল ফেরত দিতে পারে না। এর মডেল
মেটাডেটা সেই অনুযায়ী চিহ্নিত করা হয়েছে, যাতে টুল-আবশ্যক কম্বো রাউটিং এটিকে এড়িয়ে চলে।

> **বর্তমান অবস্থা: Claude Code `2.1.258`-এ পিন করা; অফলাইন ও লাইভ যাচাইকরণ সর্বশেষ
> `2.1.220`-এ রেকর্ড করা হয়েছিল।** `2.1.220` পিনটি Devin CLI
> `3000.2.17` এবং মডেল `swe-1-7-lightning`-এর মাধ্যমে তিনটি বিচ্ছিন্ন পরিস্থিতি সম্পন্ন করেছিল; সেই চূড়ান্ত লাইভ রান ক্লায়েন্ট-মালিকানাধীন `Read`,
> `Edit`, এবং `Bash` টার্ন, সফল `npm test` ফলাফল, প্রজেক্ট কমান্ড ও স্কিল
> আবিষ্কার, শুধুমাত্র-Devin রাউটিং, এবং Claude-এ শূন্য বহির্গামী ট্র্যাফিক প্রমাণ করেছিল। এরপর পিনটি `2.1.258`-এ উন্নীত করা হয়
> (OmniRoute-এর Claude পরিচয় যে CLI প্রজন্মের ছদ্মবেশ ধারণ করে এবং যা প্রথমবার
> নেটিভভাবে Fable 5.1 স্তর সরবরাহ করে)। নতুন পিনে পিন করা বেস ইমেজে ইনস্টলেশন স্তর এবং `claude --version`
> যাচাই করা হয়েছে, এবং ব্রিজ ইউনিট স্যুট, `compose config` ও
> স্ট্যাটিক আইসোলেশন প্রমাণ সফল হয়েছে — কিন্তু অফলাইন মক পরিস্থিতি এবং লাইভ তিন-পরিস্থিতির
> স্যুট এখনও পুনরায় চালানো হয়নি। এই পিনসহ ব্রিজের ওপর নির্ভর করার আগে সেগুলো পুনরায় চালান ("পিন করা টুল আপডেট করা" দেখুন)।

## আর্কিটেকচার

```text
Claude Code 2.1.258 (বিচ্ছিন্ন নন-রুট Linux কনটেইনার)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (Claude-ফরম্যাট, প্রমাণীকরণবিহীন প্রোভাইডার)
  -> devin acp --agent-type summarizer (অফিসিয়াল ACP stdio, কোনো Devin টুল নেই)
  -> নিবেদিত devin-auth ভলিউমে Devin অ্যাকাউন্ট
```

অফিসিয়াল CLI-এর ডিফল্ট ACP এজেন্ট তার নিজস্ব টুল নির্বাহ করতে পারে, তাই এই ব্রিজ সেটি ব্যবহার
করে না। এটি নির্দিষ্ট `summarizer` ACP এজেন্ট চালু করে, যার অফিসিয়াল CLI মোডে কোনো টুল নেই, এবং
সিরিয়ালাইজ করা Anthropic অনুরোধকে একটি এক্সিকিউশন ট্রেস হিসেবে ফ্রেম করে। Claude-এর মালিকানাধীন আরেকটি
অ্যাকশনের প্রয়োজন হলে, প্রতিক্রিয়ায় অবশ্যই ঠিক একটি ক্লায়েন্ট টুল এনভেলপ থাকতে হবে। কোনো ACP
`tool_call` বা `tool_call_update`-কে প্রতিক্রিয়া সফল হিসেবে রিপোর্ট করার আগেই প্রত্যাখ্যান করা হয়।

`open-sse/executors/devin-agentic/serializer.ts`-এর সিরিয়ালাইজারটি `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice`, এবং
Claude Code সরবরাহ করা টুলগুলো অক্ষুণ্ণ রাখে। ছবি এবং অজানা ব্লক স্পষ্টভাবে ব্যর্থ হয়। বড় টুল ফলাফলে
একটি দৃশ্যমান ছাঁটাই চিহ্ন ব্যবহার করা হয়।

পার্সারটি প্রতি মডেল টার্নে একটি স্বতন্ত্র `<tool>{...}</tool>` এনভেলপ গ্রহণ করে। এটি
অনুরোধের টুল তালিকার সঙ্গে নামটি যাচাই করে, সেই টুলের JSON
Schema অনুযায়ী আর্গুমেন্ট যাচাই করে, মিশ্র বর্ণনা/অ্যাকশন প্রত্যাখ্যান করে এবং একটি সীমাবদ্ধ মেরামতের অনুমতি দেয়। এরপর Claude Code
ফলস্বরূপ Anthropic `tool_use` স্থানীয়ভাবে নির্বাহ করে এবং `tool_result`-টি OmniRoute-এর মাধ্যমে
ফেরত পাঠায়।

## স্বয়ংক্রিয় রাউটিং

প্রোভাইডারটি ব্লক করা না থাকলে OmniRoute-এর `auto/*` প্রার্থী পুলে যোগ্য।
প্রার্থীর যোগ্যতা নির্বাচন নিশ্চিত করে না: কম্বোটির রাউটিং কৌশল (উদাহরণস্বরূপ,
সর্বশেষ-কার্যকর) অন্য কোনো প্রোভাইডারকে অগ্রাধিকার দিতে পারে। প্রতিটি অনুরোধ Devin-এর মাধ্যমে পাঠানো আবশ্যক হলে
`dva/<model>` বা Devin-প্রথম কম্বো ব্যবহার করুন।

## বিচ্ছিন্নতা এবং হুমকি মডেল

হোস্টের Claude ইনস্টলেশন, অ্যাকাউন্ট এবং কনফিগারেশন এই পরিধির বাইরে এবং নিষিদ্ধ হিসেবে বিবেচিত। Compose সার্ভিসগুলো:

- UID/GID `10001:10001` হিসেবে চলে, যেখানে রয়েছে একটি কেবল-পঠনযোগ্য রুট ফাইলসিস্টেম, অপসারিত capabilities এবং
  `no-new-privileges`;
- একটি ব্যক্তিগত `/home/bridge`, একটি নিবেদিত Claude কনফিগ ভলিউম, বিচ্ছিন্ন OmniRoute ডেটা
  এবং একটি পৃথক `devin-auth` ভলিউম ব্যবহার করে;
- শুধু অস্থায়ী `.sandbox` ওয়ার্কস্পেস/প্রমাণ মাউন্ট করে;
- হোস্টের home, Keychain, SSH, ক্লাউড credentials বা Docker socket মাউন্ট করে না;
- সুস্পষ্ট environments তৈরি করে এবং Anthropic API/OAuth/routing variables অপসারণ করে;
- Claude Code inference-কে শুধু একটি local-only key দিয়ে `http://omniroute:20128`-এ পাঠায়।

অফলাইন প্রোফাইলটি একটি অভ্যন্তরীণ নেটওয়ার্ক ব্যবহার করে। লাইভ প্রোফাইলে OmniRoute শুধু `network-guard`-এর মাধ্যমে
অফিশিয়াল Devin endpoints-এ পৌঁছায়; সম্পর্কহীন destinations প্রত্যাখ্যান করা হয়।
Claude Code-এর জন্য একটি পৃথক deny-all egress guard রয়েছে এবং এটি `NO_PROXY`-এর মাধ্যমে শুধু স্থানীয় OmniRoute
সার্ভিসে পৌঁছাতে পারে। Guard audit files শুধু সংশ্লিষ্ট guard process দ্বারা মাউন্ট করা হয়। স্ক্রিপ্টগুলো
token-মুক্ত প্রমাণ export করার আগে file ownership, mode, link count এবং প্রতিটি সিদ্ধান্ত যাচাই করে।

বিচ্ছিন্নতার প্রমাণটি স্বাধীনভাবে চালান:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

এটি topology, named mounts, non-root/read-only settings, সুস্পষ্ট local routing,
সংবেদনশীল environment variables-এর অনুপস্থিতি, Docker socket-এর অনুপস্থিতি, `api.anthropic.com`
ও `claude.ai`-এ অবরুদ্ধ access, Devin-only provider selection এবং ACP backend অনুপলভ্য হলে
সুস্পষ্ট failure যাচাই করে।

## প্রথমবারের সেটআপ এবং স্বাভাবিক ব্যবহার

Pinned image তৈরি করুন:

```bash
./scripts/devin-bridge/build
```

শুধু বিচ্ছিন্ন Devin volume-কে authenticate করুন:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

Login command-টি remote/container environments-এর জন্য নির্ধারিত অফিশিয়াল manual-token flow
ব্যবহার করে। মানটি সরাসরি CLI prompt-এ প্রবেশ করানো হয়; এটি process argument হিসেবে পাঠানো,
Git-এ লেখা বা হোস্ট থেকে কপি করা হয় না।

বিচ্ছিন্ন Claude Code runtime চালু করুন:

```bash
./scripts/devin-bridge/launch
```

Containerized Claude Code শুরু করার আগে `launch` বিচ্ছিন্নতা, Devin authentication এবং model discovery
পুনরায় যাচাই করে। এটি কখনোই হোস্টের Claude executable চালায় না। Model aliases `.env.devin-bridge`-এ
সেট করা যেতে পারে; কনফিগার করা প্রতিটি মানে অবশ্যই `devin-cli-agentic/` prefix বজায় রাখতে হবে।

পুনরুৎপাদনযোগ্য offline path-এর জন্য কোনো Devin account প্রয়োজন হয় না এবং এতে runtime Internet নেই:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

Authenticated opt-in live path হলো:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

একসঙ্গে অনেক ACP sessions খোলা এড়াতে live runner বিভিন্ন scenario-এর মধ্যে অপেক্ষা করে এবং
পাঠ্যভিত্তিক দাবির ওপর নির্ভর করার পরিবর্তে structured Claude stream events যাচাই করে। এর তিনটি
scenario প্রমাণ করে:

1. সরাসরি project reads এবং defect analysis;
2. একটি প্রকৃত `Edit`, client-owned `Bash` `npm test` এবং একটি terminal result;
3. `/bridge-check` এবং `bridge-proof` discovery, project reads, আরেকটি সফল
   client-owned `npm test` এবং কোনো pending work ছাড়াই completion।

চূড়ান্ত gate Devin network audit-ও পরীক্ষা করে এবং Claude egress audit খালি থাকা আবশ্যক করে।

## পিন করা টুল আপডেট করা

ইমেজটি `docker/devin-bridge/Dockerfile`-এ Node, Claude Code এবং Devin CLI-এর সংস্করণ পিন করে। আপডেট করতে:

1. স্পষ্টভাবে উল্লেখ করা সংস্করণগুলো পরিবর্তন করুন;
2. অফিসিয়াল আর্টিফ্যাক্টের মান দিয়ে উভয় আর্কিটেকচার-নির্দিষ্ট Devin আর্কাইভ চেকসাম প্রতিস্থাপন করুন;
3. পুনরায় বিল্ড করুন এবং প্রতিটি অফলাইন যাচাইকরণ কমান্ড চালান;
4. ইমেজের ভেতরের সংস্করণগুলো নিশ্চিত করুন;
5. প্রমাণীকৃত তিন-পরিস্থিতির লাইভ স্যুটটি পুনরায় চালান।

হোস্টে কোনো CLI-ই গ্লোবালি ইনস্টল করবেন না এবং চেকসাম যাচাইকরণকে কোনো
অযাচাইকৃত ডাউনলোড দিয়ে প্রতিস্থাপন করবেন না।

## নির্ণয় ও পরিষ্কারকরণ

- `docker compose -f docker/devin-bridge/compose.yml --profile offline logs omniroute`
  লোকাল রাউটিং এবং সংবেদনশীল তথ্য অপসারণ করা এক্সিকিউটর ত্রুটি দেখায়।
- `.sandbox/evidence/mock-acp.jsonl` নির্ধারিত মক ACP অ্যাকশন রেকর্ড করে।
- `.sandbox/evidence/claude-stream.jsonl` প্রকৃত Claude Code অফলাইন রান রেকর্ড করে।
- `.sandbox/evidence/live-*.jsonl` যাচাইকৃত তিনটি লাইভ স্ট্রিম রেকর্ড করে।
- `.sandbox/evidence/egress.jsonl` এবং `.sandbox/evidence/claude-egress.jsonl` হলো গার্ড অডিটের যাচাইকৃত,
  টোকেন-মুক্ত কপি।

লগইন/কনফিগ ভলিউম সংরক্ষণ করে নিজস্ব কনটেইনার এবং নেটওয়ার্ক বন্ধ করুন:

```bash
./scripts/devin-bridge/clean
```

নামযুক্ত ভলিউমসহ ব্রিজের মালিকানাধীন সম্পূর্ণ এনভায়রনমেন্ট সরিয়ে ফেলুন:

```bash
./scripts/devin-bridge/clean --all
```

## সীমাবদ্ধতা

- ব্রিজটি নির্দিষ্ট no-tools `summarizer` ভূমিকার ওপর নির্ভর করে, কারণ Devin CLI `3000.2.17`
  কোনো নিরপেক্ষ no-tools ACP এজেন্ট প্রকাশ করে না। অ্যাডাপ্টারটি সারাংশ-ধাঁচের
  মধ্যবর্তী প্রতিক্রিয়ার জন্য সমন্বয় করে, তবে একটি সীমাবদ্ধ মেরামত প্রচেষ্টা তবুও স্পষ্টভাবে ব্যর্থ হতে পারে।
- লাইভ ACP কলগুলো ক্ষণস্থায়ী `502`/`504` প্রতিক্রিয়া ফেরত দিতে পারে। হার্নেসটি পরিস্থিতিগুলোর মধ্যে বিরতি রাখে;
  ধারাবাহিক ব্যর্থতার ক্ষেত্রে fail-closed আচরণ বজায় থাকে এবং কখনোই অন্য কোনো প্রোভাইডার নির্বাচন করা হয় না।
- প্রতিটি Anthropic অনুরোধ থেকে ACP কনটেক্সট পুনর্গঠন করা হয়; কোনো প্রসেস/সেশন
  অ্যাফিনিটি নেই।
- প্রতি মডেল প্রতিক্রিয়ায় একটি টুল কল সমর্থিত; সমান্তরাল কল প্রত্যাখ্যান করা হয়।
- ইমেজ স্পষ্টভাবে অসমর্থিত। ভিশন, থিংকিং আউটপুট, এফর্ট কন্ট্রোল এবং 1M
  কনটেক্সট উইন্ডোর সমর্থন ঘোষণা করা হয় না।
- SSE বৈধ Anthropic লাইফসাইকেল ইভেন্ট ব্যবহার করে, তবে সীমাবদ্ধ ACP টার্নটি
  সংগ্রহ করার পরে তা নির্গত হয়; ACP চাঙ্কগুলো ক্রমবর্ধমানভাবে ফরওয়ার্ড করা হয় না।
