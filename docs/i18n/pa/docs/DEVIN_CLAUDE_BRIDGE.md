`devin-cli-agentic` ਅਸਲ Claude Code ਰਨਟਾਈਮ ਨੂੰ OmniRoute ਦਾ ਸਥਾਨਕ Anthropic
Messages ਐਂਡਪੌਇੰਟ ਵਰਤਣ ਦਿੰਦਾ ਹੈ, ਜਦੋਂ ਕਿ ਅਧਿਕਾਰਤ Devin CLI ACP stdio ਰਾਹੀਂ ਮਾਡਲ ਜਵਾਬ ਮੁਹੱਈਆ ਕਰਦਾ ਹੈ। ਇਹ
ਮੌਜੂਦਾ Anthropic, Claude OAuth, Claude Web, ਜਾਂ `devin-cli` ਪ੍ਰਦਾਤਾਵਾਂ ਨੂੰ ਸੋਧਦਾ ਨਹੀਂ ਹੈ।

ਕਲਾਇੰਟ-ਮਲਕੀਅਤ ਵਾਲੀਆਂ ਟੂਲ ਕਾਲਾਂ ਲਈ, Claude-ਫਾਰਮੈਟ ਵਾਲੇ ਟੂਲ-ਸਮਰੱਥ ਪ੍ਰਦਾਤਾ
`devin-cli-agentic` (ਉਪਨਾਮ `dva`) ਰਾਹੀਂ ਰੂਟ ਕਰੋ। ਪੁਰਾਣਾ `devin-cli` (`dv`) ACP ਐਗਜ਼ੀਕਿਊਟਰ
ਕੇਵਲ-ਟੈਕਸਟ ਹੈ: ਇਹ Devin ਦਾ ਬਿਨਾਂ-ਟੂਲਾਂ ਵਾਲਾ ਸਮਰਾਈਜ਼ਰ ਚਲਾਉਂਦਾ ਹੈ ਅਤੇ ਟੂਲ ਕਾਲਾਂ ਵਾਪਸ ਨਹੀਂ ਕਰ ਸਕਦਾ। ਇਸ ਦਾ ਮਾਡਲ
ਮੈਟਾਡਾਟਾ ਇਸੇ ਅਨੁਸਾਰ ਚਿੰਨ੍ਹਿਤ ਹੈ, ਤਾਂ ਜੋ ਟੂਲ-ਲੋੜੀਂਦੀ ਕਾਂਬੋ ਰੂਟਿੰਗ ਇਸ ਤੋਂ ਬਚੇ।

> **ਮੌਜੂਦਾ ਸਥਿਤੀ: ਪਿੰਨ ਕੀਤਾ Claude Code `2.1.258`; ਆਫਲਾਈਨ ਅਤੇ ਲਾਈਵ ਪ੍ਰਮਾਣਿਕਤਾ ਆਖਰੀ ਵਾਰ
> `2.1.220` ਉੱਤੇ ਦਰਜ ਕੀਤੀ ਗਈ ਸੀ।** `2.1.220` ਪਿੰਨ ਨੇ Devin CLI
> `3000.2.17` ਅਤੇ ਮਾਡਲ `swe-1-7-lightning` ਰਾਹੀਂ ਤਿੰਨ ਅਲੱਗ-ਥਲੱਗ ਸਿਨਾਰਿਓ ਪੂਰੇ ਕੀਤੇ; ਉਸ ਅੰਤਿਮ ਲਾਈਵ ਰਨ ਨੇ ਕਲਾਇੰਟ-ਮਲਕੀਅਤ ਵਾਲੇ `Read`,
> `Edit`, ਅਤੇ `Bash` ਟਰਨ, ਸਫਲ `npm test` ਨਤੀਜੇ, ਪ੍ਰੋਜੈਕਟ ਕਮਾਂਡ ਅਤੇ ਸਕਿੱਲ
> ਖੋਜ, ਕੇਵਲ-Devin ਰੂਟਿੰਗ, ਅਤੇ ਸਿਫ਼ਰ Claude ਈਗ੍ਰੈੱਸ ਸਾਬਤ ਕੀਤੇ। ਫਿਰ ਪਿੰਨ ਨੂੰ `2.1.258`
> ਤੱਕ ਵਧਾਇਆ ਗਿਆ (ਉਹ CLI ਪੀੜ੍ਹੀ ਜਿਸ ਦੀ OmniRoute ਦੀ Claude ਪਛਾਣ ਨਕਲ ਕਰਦੀ ਹੈ, ਅਤੇ ਪਹਿਲੀ ਲਾਈਨ ਜੋ
> Fable 5.1 ਟੀਅਰ ਨੂੰ ਮੂਲ ਰੂਪ ਵਿੱਚ ਸ਼ਿਪ ਕਰਦੀ ਹੈ)। ਨਵੇਂ ਪਿੰਨ ਉੱਤੇ ਪਿੰਨ ਕੀਤੀ ਬੇਸ ਇਮੇਜ ਵਿੱਚ ਇੰਸਟਾਲ ਲੇਅਰ ਅਤੇ `claude --version`
> ਦੀ ਪੁਸ਼ਟੀ ਕੀਤੀ ਗਈ, ਅਤੇ ਬ੍ਰਿਜ ਯੂਨਿਟ ਸੂਟ, `compose config` ਅਤੇ
> ਸਟੈਟਿਕ ਆਈਸੋਲੇਸ਼ਨ ਸਬੂਤ ਪਾਸ ਹੁੰਦੇ ਹਨ — ਪਰ ਆਫਲਾਈਨ ਮੌਕ ਸਿਨਾਰਿਓ ਅਤੇ ਲਾਈਵ ਤਿੰਨ-ਸਿਨਾਰਿਓ
> ਸੂਟ ਨੂੰ ਅਜੇ ਦੁਬਾਰਾ ਨਹੀਂ ਚਲਾਇਆ ਗਿਆ। ਇਸ ਪਿੰਨ ਨਾਲ ਬ੍ਰਿਜ ਉੱਤੇ ਨਿਰਭਰ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਉਨ੍ਹਾਂ ਨੂੰ ਦੁਬਾਰਾ ਚਲਾਓ
> ("ਪਿੰਨ ਕੀਤੇ ਟੂਲ ਅੱਪਡੇਟ ਕਰਨਾ" ਵੇਖੋ)।

## ਆਰਕੀਟੈਕਚਰ

```text
Claude Code 2.1.258 (ਅਲੱਗ-ਥਲੱਗ ਗੈਰ-root Linux ਕੰਟੇਨਰ)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (Claude-ਫਾਰਮੈਟ, ਬਿਨਾਂ-ਪ੍ਰਮਾਣਿਕਤਾ ਪ੍ਰਦਾਤਾ)
  -> devin acp --agent-type summarizer (ਅਧਿਕਾਰਤ ACP stdio, ਕੋਈ Devin ਟੂਲ ਨਹੀਂ)
  -> ਸਮਰਪਿਤ devin-auth ਵਾਲਿਊਮ ਵਿੱਚ Devin ਖਾਤਾ
```

ਅਧਿਕਾਰਤ CLI ਦਾ ਡਿਫਾਲਟ ACP ਏਜੰਟ ਆਪਣੇ ਟੂਲ ਚਲਾ ਸਕਦਾ ਹੈ, ਇਸ ਲਈ ਇਹ ਬ੍ਰਿਜ
ਉਸ ਨੂੰ ਨਹੀਂ ਵਰਤਦਾ। ਇਹ ਸਥਿਰ `summarizer` ACP ਏਜੰਟ ਸ਼ੁਰੂ ਕਰਦਾ ਹੈ, ਜਿਸ ਦੇ ਅਧਿਕਾਰਤ CLI ਮੋਡ ਵਿੱਚ ਕੋਈ ਟੂਲ ਨਹੀਂ ਹੁੰਦੇ, ਅਤੇ
ਸੀਰੀਅਲਾਈਜ਼ ਕੀਤੀ Anthropic ਬੇਨਤੀ ਨੂੰ ਇੱਕ ਐਗਜ਼ੀਕਿਊਸ਼ਨ ਟ੍ਰੇਸ ਵਜੋਂ ਫ੍ਰੇਮ ਕਰਦਾ ਹੈ। ਜਦੋਂ Claude-ਮਲਕੀਅਤ ਵਾਲੀ ਕੋਈ ਹੋਰ
ਕਾਰਵਾਈ ਲੋੜੀਂਦੀ ਹੋਵੇ, ਤਾਂ ਜਵਾਬ ਵਿੱਚ ਬਿਲਕੁਲ ਇੱਕ ਕਲਾਇੰਟ ਟੂਲ ਐਨਵਲਪ ਹੋਣਾ ਲਾਜ਼ਮੀ ਹੈ। ਕਿਸੇ ਵੀ ACP
`tool_call` ਜਾਂ `tool_call_update` ਨੂੰ ਜਵਾਬ ਦੇ ਸਫਲ ਹੋਣ ਦੀ ਰਿਪੋਰਟ ਕੀਤੇ ਜਾਣ ਤੋਂ ਪਹਿਲਾਂ ਹੀ ਰੱਦ ਕਰ ਦਿੱਤਾ ਜਾਂਦਾ ਹੈ।

`open-sse/executors/devin-agentic/serializer.ts` ਵਿਚਲਾ ਸੀਰੀਅਲਾਈਜ਼ਰ `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice`, ਅਤੇ
Claude Code ਵੱਲੋਂ ਦਿੱਤੇ ਟੂਲਾਂ ਨੂੰ ਸੁਰੱਖਿਅਤ ਰੱਖਦਾ ਹੈ। ਇਮੇਜ ਅਤੇ ਅਣਜਾਣ ਬਲਾਕ ਸਪਸ਼ਟ ਤੌਰ ਉੱਤੇ ਅਸਫਲ ਹੁੰਦੇ ਹਨ। ਵੱਡੇ ਟੂਲ ਨਤੀਜੇ
ਇੱਕ ਦਿਸਣਯੋਗ ਟਰੰਕੇਸ਼ਨ ਮਾਰਕਰ ਵਰਤਦੇ ਹਨ।

ਪਾਰਸਰ ਹਰ ਮਾਡਲ ਟਰਨ ਲਈ ਇੱਕ ਸੁਤੰਤਰ `<tool>{...}</tool>` ਐਨਵਲਪ ਸਵੀਕਾਰ ਕਰਦਾ ਹੈ। ਇਹ
ਬੇਨਤੀ ਦੀ ਟੂਲ ਸੂਚੀ ਨਾਲ ਨਾਮ ਦੀ ਜਾਂਚ ਕਰਦਾ ਹੈ, ਉਸ ਟੂਲ ਦੇ JSON
Schema ਦੇ ਮੁਕਾਬਲੇ ਆਰਗੂਮੈਂਟਾਂ ਦੀ ਪ੍ਰਮਾਣਿਕਤਾ ਜਾਂਚਦਾ ਹੈ, ਮਿਲੀ-ਜੁਲੀ ਵਿਆਖਿਆ/ਕਾਰਵਾਈਆਂ ਨੂੰ ਰੱਦ ਕਰਦਾ ਹੈ, ਅਤੇ ਇੱਕ ਸੀਮਿਤ ਮੁਰੰਮਤ ਦੀ ਆਗਿਆ ਦਿੰਦਾ ਹੈ। ਫਿਰ Claude Code
ਨਤੀਜੇ ਵਜੋਂ ਮਿਲੇ Anthropic `tool_use` ਨੂੰ ਸਥਾਨਕ ਤੌਰ ਉੱਤੇ ਚਲਾਉਂਦਾ ਹੈ ਅਤੇ `tool_result` ਨੂੰ OmniRoute ਰਾਹੀਂ
ਵਾਪਸ ਭੇਜਦਾ ਹੈ।

## ਆਟੋ-ਰੂਟਿੰਗ

ਜਦੋਂ ਪ੍ਰਦਾਤਾ ਬਲਾਕ ਨਾ ਹੋਵੇ, ਤਾਂ ਇਹ OmniRoute ਦੇ `auto/*` ਉਮੀਦਵਾਰ ਪੂਲਾਂ ਵਿੱਚ ਯੋਗ ਹੁੰਦਾ ਹੈ।
ਉਮੀਦਵਾਰ ਯੋਗਤਾ ਚੋਣ ਦੀ ਗਾਰੰਟੀ ਨਹੀਂ ਦਿੰਦੀ: ਕਾਂਬੋ ਦੀ ਰੂਟਿੰਗ ਰਣਨੀਤੀ (ਉਦਾਹਰਨ ਲਈ,
ਆਖਰੀ-ਜਾਣਿਆ-ਚੰਗਾ) ਕਿਸੇ ਹੋਰ ਪ੍ਰਦਾਤਾ ਨੂੰ ਤਰਜੀਹ ਦੇ ਸਕਦੀ ਹੈ। ਜਦੋਂ ਤੁਹਾਨੂੰ ਹਰ ਬੇਨਤੀ Devin ਰਾਹੀਂ ਭੇਜਣੀ ਲਾਜ਼ਮੀ ਹੋਵੇ, ਤਾਂ
`dva/<model>` ਜਾਂ Devin-ਪਹਿਲਾਂ ਕਾਂਬੋ ਵਰਤੋ।

## ਆਈਸੋਲੇਸ਼ਨ ਅਤੇ ਖਤਰਾ ਮਾਡਲ

ਹੋਸਟ ਦੀ Claude ਇੰਸਟਾਲੇਸ਼ਨ, ਖਾਤਾ ਅਤੇ ਸੰਰਚਨਾ ਦਾਇਰੇ ਤੋਂ ਬਾਹਰ ਹਨ ਅਤੇ ਉਨ੍ਹਾਂ ਨੂੰ
ਵਰਜਿਤ ਮੰਨਿਆ ਜਾਂਦਾ ਹੈ। Compose ਸੇਵਾਵਾਂ:

- UID/GID `10001:10001` ਵਜੋਂ, ਕੇਵਲ-ਪੜ੍ਹਨਯੋਗ ਰੂਟ ਫ਼ਾਈਲ ਸਿਸਟਮ, ਹਟਾਈਆਂ ਗਈਆਂ ਸਮਰੱਥਾਵਾਂ ਅਤੇ
  `no-new-privileges` ਨਾਲ ਚੱਲਦੀਆਂ ਹਨ;
- ਇੱਕ ਨਿੱਜੀ `/home/bridge`, ਇੱਕ ਸਮਰਪਿਤ Claude ਸੰਰਚਨਾ ਵਾਲਿਊਮ, ਵੱਖਰਾ OmniRoute ਡਾਟਾ,
  ਅਤੇ ਇੱਕ ਅਲੱਗ `devin-auth` ਵਾਲਿਊਮ ਵਰਤਦੀਆਂ ਹਨ;
- ਸਿਰਫ਼ ਅਸਥਾਈ `.sandbox` ਵਰਕਸਪੇਸ/ਸਬੂਤ ਮਾਊਂਟ ਕਰਦੀਆਂ ਹਨ;
- ਹੋਸਟ ਹੋਮ, Keychain, SSH, ਕਲਾਊਡ ਕ੍ਰੈਡੈਂਸ਼ਲ ਜਾਂ Docker ਸਾਕਟ ਮਾਊਂਟ ਨਹੀਂ ਕਰਦੀਆਂ;
- ਸਪਸ਼ਟ ਇਨਵਾਇਰਨਮੈਂਟ ਬਣਾਉਂਦੀਆਂ ਹਨ ਅਤੇ Anthropic API/OAuth/ਰੂਟਿੰਗ ਵੇਰੀਏਬਲ ਹਟਾਉਂਦੀਆਂ ਹਨ;
- Claude Code ਇਨਫ਼ਰੈਂਸ ਨੂੰ ਸਿਰਫ਼ ਇੱਕ ਲੋਕਲ-ਮਾਤਰ ਕੁੰਜੀ ਨਾਲ `http://omniroute:20128` ਵੱਲ ਭੇਜਦੀਆਂ ਹਨ।

ਆਫ਼ਲਾਈਨ ਪ੍ਰੋਫ਼ਾਈਲ ਇੱਕ ਅੰਦਰੂਨੀ ਨੈੱਟਵਰਕ ਵਰਤਦਾ ਹੈ। ਲਾਈਵ ਪ੍ਰੋਫ਼ਾਈਲ ਵਿੱਚ, OmniRoute ਅਧਿਕਾਰਤ
Devin ਐਂਡਪੌਇੰਟਾਂ ਤੱਕ ਸਿਰਫ਼ `network-guard` ਰਾਹੀਂ ਪਹੁੰਚਦਾ ਹੈ; ਗੈਰ-ਸੰਬੰਧਿਤ ਮੰਜ਼ਿਲਾਂ ਨੂੰ ਅਸਵੀਕਾਰ ਕੀਤਾ ਜਾਂਦਾ ਹੈ।
Claude Code ਕੋਲ ਇੱਕ ਵੱਖਰਾ ਸਾਰੇ ਈਗ੍ਰੈੱਸ ਨੂੰ ਅਸਵੀਕਾਰ ਕਰਨ ਵਾਲਾ ਗਾਰਡ ਹੈ ਅਤੇ ਉਹ `NO_PROXY` ਰਾਹੀਂ ਸਿਰਫ਼ ਲੋਕਲ OmniRoute
ਸੇਵਾ ਤੱਕ ਪਹੁੰਚ ਸਕਦਾ ਹੈ। ਗਾਰਡ ਆਡਿਟ ਫ਼ਾਈਲਾਂ ਸਿਰਫ਼ ਉਨ੍ਹਾਂ ਦੀ ਗਾਰਡ ਪ੍ਰਕਿਰਿਆ ਦੁਆਰਾ ਮਾਊਂਟ ਕੀਤੀਆਂ ਜਾਂਦੀਆਂ ਹਨ। ਸਕ੍ਰਿਪਟਾਂ
ਟੋਕਨ-ਰਹਿਤ ਸਬੂਤ ਨਿਰਯਾਤ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਫ਼ਾਈਲ ਮਾਲਕੀ, ਮੋਡ, ਲਿੰਕ ਗਿਣਤੀ ਅਤੇ ਹਰ ਫ਼ੈਸਲੇ ਦੀ ਪੁਸ਼ਟੀ ਕਰਦੀਆਂ ਹਨ।

ਆਈਸੋਲੇਸ਼ਨ ਸਬੂਤ ਨੂੰ ਸੁਤੰਤਰ ਤੌਰ 'ਤੇ ਚਲਾਓ:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

ਇਹ ਟੋਪੋਲੋਜੀ, ਨਾਮਿਤ ਮਾਊਂਟਾਂ, ਗੈਰ-ਰੂਟ/ਕੇਵਲ-ਪੜ੍ਹਨਯੋਗ ਸੈਟਿੰਗਾਂ, ਸਪਸ਼ਟ ਲੋਕਲ ਰੂਟਿੰਗ,
ਸੰਵੇਦਨਸ਼ੀਲ ਇਨਵਾਇਰਨਮੈਂਟ ਵੇਰੀਏਬਲਾਂ ਦੀ ਗੈਰਹਾਜ਼ਰੀ, Docker ਸਾਕਟ ਦੀ ਗੈਰਹਾਜ਼ਰੀ, `api.anthropic.com`
ਅਤੇ `claude.ai` ਤੱਕ ਬਲੌਕ ਕੀਤੀ ਪਹੁੰਚ, ਕੇਵਲ-Devin ਪ੍ਰਦਾਤਾ ਚੋਣ ਅਤੇ ACP ਬੈਕਐਂਡ ਉਪਲਬਧ ਨਾ ਹੋਣ 'ਤੇ
ਸਪਸ਼ਟ ਅਸਫਲਤਾ ਨੂੰ ਪ੍ਰਮਾਣਿਤ ਕਰਦਾ ਹੈ।

## ਪਹਿਲੀ ਵਾਰ ਦੀ ਸੈਟਅੱਪ ਅਤੇ ਆਮ ਵਰਤੋਂ

ਪਿੰਨ ਕੀਤੀ ਇਮੇਜ ਬਣਾਓ:

```bash
./scripts/devin-bridge/build
```

ਸਿਰਫ਼ ਆਈਸੋਲੇਟ ਕੀਤੇ Devin ਵਾਲਿਊਮ ਨੂੰ ਪ੍ਰਮਾਣਿਤ ਕਰੋ:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

ਲੌਗਇਨ ਕਮਾਂਡ ਰਿਮੋਟ/ਕੰਟੇਨਰ ਇਨਵਾਇਰਨਮੈਂਟਾਂ ਲਈ ਬਣਾਇਆ ਗਿਆ ਅਧਿਕਾਰਤ ਮੈਨੁਅਲ-ਟੋਕਨ ਪ੍ਰਵਾਹ ਵਰਤਦੀ ਹੈ।
ਮੁੱਲ ਸਿੱਧਾ CLI ਪ੍ਰੌਂਪਟ ਵਿੱਚ ਦਰਜ ਕੀਤਾ ਜਾਂਦਾ ਹੈ; ਇਸਨੂੰ ਪ੍ਰਕਿਰਿਆ ਆਰਗੂਮੈਂਟ ਵਜੋਂ ਪਾਸ ਨਹੀਂ ਕੀਤਾ ਜਾਂਦਾ,
Git ਵਿੱਚ ਨਹੀਂ ਲਿਖਿਆ ਜਾਂਦਾ ਅਤੇ ਨਾ ਹੀ ਹੋਸਟ ਤੋਂ ਕਾਪੀ ਕੀਤਾ ਜਾਂਦਾ ਹੈ।

ਆਈਸੋਲੇਟ ਕੀਤਾ Claude Code ਰਨਟਾਈਮ ਲਾਂਚ ਕਰੋ:

```bash
./scripts/devin-bridge/launch
```

`launch` ਕੰਟੇਨਰਬੱਧ Claude Code ਸ਼ੁਰੂ ਕਰਨ ਤੋਂ ਪਹਿਲਾਂ ਆਈਸੋਲੇਸ਼ਨ, Devin ਪ੍ਰਮਾਣੀਕਰਨ ਅਤੇ ਮਾਡਲ ਖੋਜ ਦੀ
ਮੁੜ ਜਾਂਚ ਕਰਦਾ ਹੈ। ਇਹ ਕਦੇ ਵੀ ਹੋਸਟ ਦਾ Claude ਐਗਜ਼ੀਕਿਊਟੇਬਲ ਨਹੀਂ ਚਲਾਉਂਦਾ। ਮਾਡਲ ਉਪਨਾਮ
`.env.devin-bridge` ਵਿੱਚ ਸੈੱਟ ਕੀਤੇ ਜਾ ਸਕਦੇ ਹਨ; ਹਰ ਸੰਰਚਿਤ ਮੁੱਲ ਵਿੱਚ
`devin-cli-agentic/` ਪ੍ਰੀਫਿਕਸ ਬਰਕਰਾਰ ਰਹਿਣਾ ਲਾਜ਼ਮੀ ਹੈ।

## ਪ੍ਰਮਾਣੀਕਰਨ ਕਮਾਂਡਾਂ

ਦੁਹਰਾਏ ਜਾ ਸਕਣ ਵਾਲੇ ਆਫ਼ਲਾਈਨ ਮਾਰਗ ਨੂੰ ਕਿਸੇ Devin ਖਾਤੇ ਦੀ ਲੋੜ ਨਹੀਂ ਹੈ ਅਤੇ ਇਸ ਵਿੱਚ ਕੋਈ ਰਨਟਾਈਮ ਇੰਟਰਨੈੱਟ ਨਹੀਂ ਹੈ:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

ਪ੍ਰਮਾਣਿਤ, ਚੋਣਵਾਂ ਲਾਈਵ ਮਾਰਗ ਇਹ ਹੈ:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

ਲਾਈਵ ਰਨਰ ACP ਸੈਸ਼ਨਾਂ ਨੂੰ ਇੱਕੋ ਵਾਰ ਵੱਡੀ ਗਿਣਤੀ ਵਿੱਚ ਖੋਲ੍ਹਣ ਤੋਂ ਬਚਣ ਲਈ ਦ੍ਰਿਸ਼ਾਂ ਵਿਚਕਾਰ ਉਡੀਕ ਕਰਦਾ ਹੈ ਅਤੇ
ਲਿਖਤੀ ਦਾਅਵਿਆਂ 'ਤੇ ਭਰੋਸਾ ਕਰਨ ਦੀ ਬਜਾਏ ਸੰਰਚਿਤ Claude ਸਟ੍ਰੀਮ ਈਵੈਂਟਾਂ ਨੂੰ ਪ੍ਰਮਾਣਿਤ ਕਰਦਾ ਹੈ। ਇਸਦੇ ਤਿੰਨ
ਦ੍ਰਿਸ਼ ਇਹ ਸਾਬਤ ਕਰਦੇ ਹਨ:

1. ਸਿੱਧੇ ਪ੍ਰੋਜੈਕਟ ਰੀਡ ਅਤੇ ਖਾਮੀ ਵਿਸ਼ਲੇਸ਼ਣ;
2. ਇੱਕ ਅਸਲੀ `Edit`, ਕਲਾਇੰਟ-ਮਲਕੀਅਤ ਵਾਲਾ `Bash` `npm test`, ਅਤੇ ਇੱਕ ਟਰਮੀਨਲ ਨਤੀਜਾ;
3. `/bridge-check` ਦੇ ਨਾਲ `bridge-proof` ਖੋਜ, ਪ੍ਰੋਜੈਕਟ ਰੀਡ, ਇੱਕ ਹੋਰ ਸਫਲ
   ਕਲਾਇੰਟ-ਮਲਕੀਅਤ ਵਾਲਾ `npm test`, ਅਤੇ ਬਿਨਾਂ ਬਕਾਇਆ ਕੰਮ ਦੇ ਪੂਰਨਤਾ।

ਅੰਤਿਮ ਗੇਟ Devin ਨੈੱਟਵਰਕ ਆਡਿਟ ਦੀ ਵੀ ਜਾਂਚ ਕਰਦਾ ਹੈ ਅਤੇ Claude ਈਗ੍ਰੈੱਸ ਆਡਿਟ ਦਾ
ਖਾਲੀ ਰਹਿਣਾ ਲਾਜ਼ਮੀ ਕਰਦਾ ਹੈ।

## ਪਿੰਨ ਕੀਤੇ ਟੂਲ ਅੱਪਡੇਟ ਕਰਨਾ

ਇਮੇਜ ਵਿੱਚ Node, Claude Code, ਅਤੇ Devin CLI ਨੂੰ
`docker/devin-bridge/Dockerfile` ਵਿੱਚ ਪਿੰਨ ਕੀਤਾ ਗਿਆ ਹੈ। ਅੱਪਡੇਟ ਕਰਨ ਲਈ:

1. ਸਪਸ਼ਟ ਵਰਜਨ ਬਦਲੋ;
2. ਦੋਵੇਂ ਆਰਕੀਟੈਕਚਰ-ਵਿਸ਼ੇਸ਼ Devin ਆਰਕਾਈਵ ਚੈਕਸਮਾਂ ਨੂੰ ਅਧਿਕਾਰਤ
   ਆਰਟੀਫੈਕਟ ਦੇ ਮੁੱਲਾਂ ਨਾਲ ਬਦਲੋ;
3. ਮੁੜ ਬਿਲਡ ਕਰੋ ਅਤੇ ਹਰ ਆਫਲਾਈਨ ਪ੍ਰਮਾਣਿਕਤਾ ਕਮਾਂਡ ਚਲਾਓ;
4. ਇਮੇਜ ਦੇ ਅੰਦਰ ਵਰਜਨਾਂ ਦੀ ਪੁਸ਼ਟੀ ਕਰੋ;
5. ਪ੍ਰਮਾਣਿਤ ਤਿੰਨ-ਦ੍ਰਿਸ਼ ਲਾਈਵ ਸੂਟ ਨੂੰ ਦੁਬਾਰਾ ਚਲਾਓ।

ਕਿਸੇ ਵੀ CLI ਨੂੰ ਹੋਸਟ ਉੱਤੇ ਗਲੋਬਲੀ ਇੰਸਟਾਲ ਨਾ ਕਰੋ ਅਤੇ ਨਾ ਹੀ ਚੈਕਸਮ ਤਸਦੀਕ ਨੂੰ ਕਿਸੇ
ਗੈਰ-ਤਸਦੀਕਸ਼ੁਦਾ ਡਾਊਨਲੋਡ ਨਾਲ ਬਦਲੋ।

## ਸੀਮਾਵਾਂ

- ਬ੍ਰਿਜ ਸਥਿਰ, ਬਿਨਾਂ-ਟੂਲਾਂ ਵਾਲੀ `summarizer` ਭੂਮਿਕਾ ਉੱਤੇ ਨਿਰਭਰ ਕਰਦਾ ਹੈ ਕਿਉਂਕਿ Devin CLI `3000.2.17`
  ਕੋਈ ਨਿਰਪੱਖ, ਬਿਨਾਂ-ਟੂਲਾਂ ਵਾਲਾ ACP ਏਜੰਟ ਉਪਲਬਧ ਨਹੀਂ ਕਰਦਾ। ਐਡਾਪਟਰ ਸੰਖੇਪ-ਆਕਾਰ ਵਾਲੇ
  ਵਿਚਕਾਰਲੇ ਜਵਾਬਾਂ ਦੀ ਭਰਪਾਈ ਕਰਦਾ ਹੈ, ਪਰ ਇੱਕ ਸੀਮਿਤ ਮੁਰੰਮਤ ਫਿਰ ਵੀ ਸਪਸ਼ਟ ਤੌਰ ਉੱਤੇ ਅਸਫਲ ਹੋ ਸਕਦੀ ਹੈ।
- ਲਾਈਵ ACP ਕਾਲਾਂ ਅਸਥਾਈ `502`/`504` ਜਵਾਬ ਵਾਪਸ ਕਰ ਸਕਦੀਆਂ ਹਨ। ਹਾਰਨੈੱਸ ਦ੍ਰਿਸ਼ਾਂ ਵਿਚਕਾਰ ਅੰਤਰ ਰੱਖਦਾ ਹੈ;
  ਲਗਾਤਾਰ ਅਸਫਲਤਾ ਫੇਲ-ਕਲੋਜ਼ਡ ਰਹਿੰਦੀ ਹੈ ਅਤੇ ਕਦੇ ਵੀ ਕੋਈ ਹੋਰ ਪ੍ਰਦਾਤਾ ਨਹੀਂ ਚੁਣਦੀ।
- ACP ਸੰਦਰਭ ਨੂੰ ਹਰ Anthropic ਬੇਨਤੀ ਤੋਂ ਮੁੜ ਬਣਾਇਆ ਜਾਂਦਾ ਹੈ; ਕੋਈ ਪ੍ਰਕਿਰਿਆ/ਸੈਸ਼ਨ
  ਅਫ਼ਿਨਿਟੀ ਨਹੀਂ ਹੈ।
- ਹਰ ਮਾਡਲ ਜਵਾਬ ਲਈ ਇੱਕ ਟੂਲ ਕਾਲ ਸਮਰਥਿਤ ਹੈ; ਸਮਾਂਤਰ ਕਾਲਾਂ ਰੱਦ ਕੀਤੀਆਂ ਜਾਂਦੀਆਂ ਹਨ।
- ਇਮੇਜਾਂ ਸਪਸ਼ਟ ਤੌਰ ਉੱਤੇ ਅਸਮਰਥਿਤ ਹਨ। ਵਿਜ਼ਨ, ਥਿੰਕਿੰਗ ਆਉਟਪੁੱਟ, ਐਫ਼ਰਟ ਕੰਟਰੋਲ, ਅਤੇ 1M
  ਸੰਦਰਭ ਵਿੰਡੋ ਦਾ ਇਸ਼ਤਿਹਾਰ ਨਹੀਂ ਦਿੱਤਾ ਜਾਂਦਾ।
- SSE ਵੈਧ Anthropic ਲਾਈਫਸਾਈਕਲ ਇਵੈਂਟ ਵਰਤਦਾ ਹੈ, ਪਰ ਇਹ ਸੀਮਿਤ ACP ਟਰਨ ਇਕੱਠਾ ਹੋਣ ਤੋਂ ਬਾਅਦ
  ਨਿਕਾਸ ਕੀਤਾ ਜਾਂਦਾ ਹੈ; ACP ਚੰਕ ਕ੍ਰਮਵਾਰ ਤੁਰੰਤ ਅੱਗੇ ਨਹੀਂ ਭੇਜੇ ਜਾਂਦੇ।
