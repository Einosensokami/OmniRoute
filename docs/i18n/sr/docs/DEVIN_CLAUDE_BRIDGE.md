`devin-cli-agentic` омогућава стварном Claude Code окружењу да користи OmniRoute-ову локалну Anthropic
Messages крајњу тачку, док званични Devin CLI испоручује одговоре модела преко ACP stdio-а. Он
не мења постојеће Anthropic, Claude OAuth, Claude Web или `devin-cli` провајдере.

За позиве алата којима управља клијент, усмеравајте преко `devin-cli-agentic` (алијас `dva`),
провајдера који подржава алате у Claude формату. Застарели `devin-cli` (`dv`) ACP извршилац
подржава само текст: покреће Devin-ов сумаризатор без алата и не може да врати позиве алата. Његови
метаподаци модела су означени у складу с тим, тако да ће га комбиновано усмеравање које захтева алате избегавати.

> **Тренутни статус: Claude Code је фиксиран на верзију `2.1.258`; офлајн и жива валидација последњи пут су забележене
> на верзији `2.1.220`.** Фиксирана верзија `2.1.220` успешно је завршила три изолована сценарија преко Devin CLI-ја
> `3000.2.17` и модела `swe-1-7-lightning`; то завршно живо покретање потврдило је клијентске `Read`,
> `Edit` и `Bash` кораке, успешне резултате за `npm test`, откривање пројектних команди и вештина,
> усмеравање искључиво преко Devin-а и нулти одлазни саобраћај ка Claude-у. Фиксирана верзија је затим подигнута на `2.1.258`
> (генерацију CLI-ја коју OmniRoute-ов Claude идентитет имитира и прву линију која изворно испоручује
> ниво Fable 5.1). На новој фиксираној верзији, инсталациони слој и `claude --version` проверени су
> на фиксираној основној слици, а скуп јединичних тестова моста, `compose config` и
> статички доказ изолације пролазе — али офлајн сценарио са лажним сервисом и живи скуп од три сценарија
> још нису поново покренути. Поново их покрените (погледајте „Ажурирање фиксираних алата“) пре него што се
> ослоните на мост са овом фиксираном верзијом.

## Архитектура

```text
Claude Code 2.1.258 (изоловани Linux контејнер без root привилегија)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (Claude формат, провајдер без аутентификације)
  -> devin acp --agent-type summarizer (званични ACP stdio, без Devin алата)
  -> Devin налог у наменском devin-auth волумену
```

Подразумевани ACP агент званичног CLI-ја може да извршава сопствене алате, па га овај мост не користи.
Он покреће фиксни `summarizer` ACP агент, чији званични CLI режим нема алате, и
уоквирује серијализовани Anthropic захтев као траг извршавања. Када је потребна још једна радња
којом управља Claude, одговор мора да садржи тачно један омотач клијентског алата. Сваки ACP
`tool_call` или `tool_call_update` одбија се пре него што одговор може бити пријављен као
успешан.

Серијализатор у `open-sse/executors/devin-agentic/serializer.ts` чува `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice` и
алате које доставља Claude Code. Слике и непознати блокови изричито изазивају неуспех. Велики резултати алата
користе видљиву ознаку скраћивања.

Парсер прихвата један самостални `<tool>{...}</tool>` омотач по кораку модела. Он проверава
име у односу на листу алата из захтева, валидира аргументе према JSON Schema-и тог алата,
одбија мешање нарације и радњи и дозвољава једну ограничену исправку. Claude Code затим
локално извршава резултујући Anthropic `tool_use` и шаље `tool_result` назад преко
OmniRoute-а.

## Аутоматско усмеравање

Провајдер испуњава услове за OmniRoute-ове `auto/*` скупове кандидата када није блокиран.
Испуњавање услова не гарантује избор: стратегија усмеравања комбинације (на пример,
последњи познати исправан избор) може дати предност другом провајдеру. Користите `dva/<model>` или комбинацију
са Devin-ом на првом месту када захтевате да сваки захтев буде усмерен преко Devin-а.

## Izolacija i model pretnji

Claude instalacija, nalog i konfiguracija na hostu nisu obuhvaćeni i smatraju se
zabranjenim. Compose servisi:

- rade kao UID/GID `10001:10001`, sa korenskim sistemom datoteka samo za čitanje, uklonjenim privilegijama i opcijom
  `no-new-privileges`;
- koriste privatni `/home/bridge`, namenski volumen za Claude konfiguraciju, izolovane OmniRoute podatke
  i zaseban `devin-auth` volumen;
- montiraju samo jednokratne `.sandbox` radne prostore/dokaze;
- ne montiraju matični direktorijum hosta, Keychain, SSH, akreditive za cloud ili Docker soket;
- konstruišu eksplicitna okruženja i uklanjaju Anthropic API/OAuth/ruting promenljive;
- usmeravaju Claude Code inferenciju isključivo ka `http://omniroute:20128`, uz ključ namenjen samo za lokalnu upotrebu.

Profil van mreže koristi internu mrežu. U aktivnom profilu, OmniRoute pristupa
zvaničnim Devin krajnjim tačkama isključivo preko `network-guard`; druga odredišta su odbijena.
Claude Code ima zasebnu zabranu svog odlaznog saobraćaja i može da pristupi samo lokalnom OmniRoute
servisu preko `NO_PROXY`. Datoteke evidencije zaštitnih procesa montira isključivo odgovarajući zaštitni proces.
Skripte proveravaju vlasništvo nad datotekama, režim, broj veza i svaku odluku pre izvoza
dokaza bez tokena.

Nezavisno pokrenite dokaz izolacije:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

On proverava topologiju, imenovana montiranja, podešavanja za rad bez root privilegija i samo za čitanje, eksplicitno lokalno rutiranje,
odsustvo osetljivih promenljivih okruženja, odsustvo Docker soketa, blokirani pristup lokacijama
`api.anthropic.com` i `claude.ai`, izbor provajdera ograničen samo na Devin i eksplicitan neuspeh kada
ACP pozadinski sistem nije dostupan.

## Prvo podešavanje i uobičajena upotreba

Izgradite fiksiranu sliku:

```bash
./scripts/devin-bridge/build
```

Autentifikujte samo izolovani Devin volumen:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

Komanda za prijavljivanje koristi zvanični tok sa ručnim unosom tokena, namenjen udaljenim/kontejnerskim
okruženjima. Vrednost se unosi direktno u CLI upit; ne prosleđuje se kao
argument procesa, ne upisuje se u Git niti se kopira sa hosta.

Pokrenite izolovano Claude Code izvršno okruženje:

```bash
./scripts/devin-bridge/launch
```

`launch` ponovo proverava izolaciju, Devin autentifikaciju i otkrivanje modela pre pokretanja
kontejnerizovanog Claude Code-a. Nikada ne pokreće Claude izvršnu datoteku sa hosta. Alijasi modela mogu da se
podese u `.env.devin-bridge`; svaka konfigurisana vrednost mora da zadrži prefiks
`devin-cli-agentic/`.

## Komande za validaciju

Ponovljiva putanja van mreže ne zahteva Devin nalog i nema pristup Internetu tokom izvršavanja:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

Aktivna putanja sa autentifikacijom, koja se izričito uključuje, jeste:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

Aktivni pokretač čeka između scenarija kako bi izbegao naglo otvaranje ACP sesija i
validira strukturirane događaje Claude toka umesto da veruje tekstualnim tvrdnjama. Njegova tri
scenarija dokazuju:

1. direktno čitanje projekta i analizu nedostataka;
2. stvarni `Edit`, `Bash` `npm test` kojim upravlja klijent i terminalni rezultat;
3. `/bridge-check` uz otkrivanje `bridge-proof`, čitanje projekta, još jedno uspešno
   `npm test` kojim upravlja klijent i završetak bez posla na čekanju.

Završna kontrola takođe proverava evidenciju Devin mreže i zahteva da evidencija odlaznog Claude saobraćaja
ostane prazna.

## Ажурирање фиксираних алата

Имиџ фиксира верзије за Node, Claude Code и Devin CLI у
`docker/devin-bridge/Dockerfile`. За ажурирање:

1. промените експлицитно наведене верзије;
2. замените контролне суме Devin архива за обе архитектуре вредностима за званични
   артефакт;
3. поново изградите имиџ и покрените сваку команду за валидацију ван мреже;
4. потврдите верзије унутар имиџа;
5. поново покрените аутентификовани live пакет са три сценарија.

Немојте глобално инсталирати ниједан CLI на хосту нити заменити проверу контролне суме
непровереним преузимањем.

## Дијагностика и чишћење

- `docker compose -f docker/devin-bridge/compose.yml --profile offline logs omniroute`
  приказује локално усмеравање и санитизоване грешке извршиоца.
- `.sandbox/evidence/mock-acp.jsonl` бележи детерминистичке mock ACP радње.
- `.sandbox/evidence/claude-stream.jsonl` бележи стварно покретање Claude Code-а ван мреже.
- `.sandbox/evidence/live-*.jsonl` бележи три валидирана live тока.
- `.sandbox/evidence/egress.jsonl` и `.sandbox/evidence/claude-egress.jsonl` су валидиране
  копије ревизија заштите без токена.

Зауставите припадајуће контејнере и мреже, уз очување волумена за пријаву/конфигурацију:

```bash
./scripts/devin-bridge/clean
```

Уклоните целокупно окружење које припада мосту, укључујући именоване волумене:

```bash
./scripts/devin-bridge/clean --all
```

## Ограничења

- Мост се ослања на фиксну `summarizer` улогу без алата јер Devin CLI `3000.2.17`
  не пружа неутралног ACP агента без алата. Адаптер компензује међуодговоре обликоване
  као резимеи, али једна ограничена поправка и даље може експлицитно да не успе.
- Live ACP позиви могу вратити пролазне `502`/`504` одговоре. Систем за тестирање прави
  размак између сценарија; трајни неуспех остаје затворен и никада не бира другог провајдера.
- ACP контекст се реконструише из сваког Anthropic захтева; не постоји афинитет
  процеса/сесије.
- Подржан је један позив алата по одговору модела; паралелни позиви се одбијају.
- Слике експлицитно нису подржане. Могућности вида, излаз размишљања, контроле напора и
  контекстни прозор од 1M нису оглашени.
- SSE користи важеће Anthropic догађаје животног циклуса, али се емитује након што се
  прикупи ограничени ACP корак; ACP фрагменти се не прослеђују инкрементално.
