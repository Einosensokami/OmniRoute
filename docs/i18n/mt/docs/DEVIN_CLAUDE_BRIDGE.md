`devin-cli-agentic` jippermetti lir-runtime reali ta’ Claude Code juża l-endpoint lokali ta’ OmniRoute għall-Messaġġi ta’ Anthropic filwaqt li s-CLI uffiċjali ta’ Devin jipprovdi t-tweġibiet tal-mudell permezz ta’ ACP stdio. Dan ma jimmodifikax il-fornituri eżistenti ta’ Anthropic, Claude OAuth, Claude Web, jew `devin-cli`.

Għal sejħiet tal-għodod ikkontrollati mill-klijent, uża r-rotta permezz ta’ `devin-cli-agentic` (magħruf ukoll bħala `dva`), il-fornitur bil-format ta’ Claude li jappoġġja l-għodod. L-eżekutur ACP preċedenti `devin-cli` (`dv`) jaħdem bit-test biss: iħaddem is-sommarizzatur ta’ Devin mingħajr għodod u ma jistax jirritorna sejħiet tal-għodod. Il-metadata tal-mudell tiegħu hija mmarkata skont dan sabiex ir-routing ikkombinat li jeħtieġ l-għodod jevitah.

> **L-istatus attwali: Claude Code `2.1.258` iffissat; l-aħħar validazzjoni offline u live ġiet irreġistrata
> fuq `2.1.220`.** Il-verżjoni ffissata `2.1.220` lestiet tliet xenarji iżolati permezz ta’ Devin CLI
> `3000.2.17` u l-mudell `swe-1-7-lightning`; dik l-aħħar eżekuzzjoni live wriet turni `Read`,
> `Edit`, u `Bash` ikkontrollati mill-klijent, riżultati ta’ `npm test` li rnexxew, skoperta tal-kmandi u l-ħiliet
> tal-proġett, routing permezz ta’ Devin biss, u żero traffiku ħiereġ lejn Claude. Il-verżjoni ffissata mbagħad ittellgħet għal `2.1.258`
> (il-ġenerazzjoni tas-CLI li tissimula l-identità ta’ Claude ta’ OmniRoute, u l-ewwel linja li tinkludi
> l-livell Fable 5.1 b’mod nattiv). Fuq il-verżjoni l-ġdida, is-saff tal-installazzjoni u `claude --version`
> ġew ivverifikati fuq l-immaġni bażi ffissata, u s-sett ta’ testijiet unitarji tal-bridge, `compose config` u l-
> prova statika tal-iżolament jgħaddu — iżda x-xenarju mock offline u s-sett live ta’ tliet xenarji
> għadhom ma reġgħux ġew eżegwiti. Erġa’ eżegwihom (ara "Aġġornament tal-għodod iffissati") qabel ma tiddependi fuq
> il-bridge b’din il-verżjoni ffissata.

## Arkitettura

```text
Claude Code 2.1.258 (kontenitur Linux iżolat mhux root)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (format ta’ Claude, fornitur mingħajr awtentikazzjoni)
  -> devin acp --agent-type summarizer (ACP stdio uffiċjali, mingħajr għodod ta’ Devin)
  -> Kont ta’ Devin fil-volum iddedikat devin-auth
```

L-aġent ACP predefinit tas-CLI uffiċjali jista’ jeżegwixxi l-għodod tiegħu stess, għalhekk dan il-bridge ma jużahx. Huwa jibda l-aġent ACP fiss `summarizer`, li l-modalità uffiċjali tiegħu tas-CLI ma għandhiex għodod, u jqiegħed it-talba serializzata ta’ Anthropic f’qafas bħala traċċa tal-eżekuzzjoni. Meta tkun meħtieġa azzjoni oħra kkontrollata minn Claude, it-tweġiba trid tinkludi eżattament envelope wieħed tal-għodda tal-klijent. Kwalunkwe `tool_call` jew `tool_call_update` ta’ ACP jiġi miċħud qabel ma tweġiba tkun tista’ tiġi rrappurtata bħala waħda li rnexxiet.

Is-serializer f’`open-sse/executors/devin-agentic/serializer.ts` jippreserva `system`, `text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice`, u l-għodod ipprovduti minn Claude Code. L-immaġnijiet u l-blokki mhux magħrufa jfallu b’mod espliċitu. Riżultati kbar tal-għodod jużaw markatur viżibbli tat-tronkament.

Il-parser jaċċetta envelope awtonomu wieħed `<tool>{...}</tool>` għal kull turn tal-mudell. Huwa jivverifika l-isem mal-lista tal-għodod tat-talba, jivvalida l-argumenti skont il-JSON Schema ta’ dik l-għodda, jirrifjuta taħlit ta’ narrattiva u azzjonijiet, u jippermetti tentattiv wieħed limitat ta’ tiswija. Claude Code mbagħad jeżegwixxi lokalment l-`tool_use` ta’ Anthropic li jirriżulta u jibgħat it-`tool_result` lura permezz ta’ OmniRoute.

## Routing awtomatiku

Il-fornitur huwa eliġibbli fil-gruppi ta’ kandidati `auto/*` ta’ OmniRoute meta ma jkunx imblukkat. L-eliġibbiltà ta’ kandidat ma tiggarantix l-għażla: l-istrateġija tar-routing tal-kombinazzjoni (pereżempju, l-aħħar waħda magħrufa li taħdem) tista’ tippreferi fornitur ieħor. Uża `dva/<model>` jew kombinazzjoni li tagħti prijorità lil Devin meta tkun teħtieġ li kull talba tgħaddi minn Devin.

## Iżolament u mudell tat-theddid

L-installazzjoni, il-kont u l-konfigurazzjoni ta' Claude fuq il-host huma barra mill-ambitu u jitqiesu bħala
pprojbiti. Is-servizzi Compose:

- jitħaddmu bħala UID/GID `10001:10001`, b'sistema tal-fajls root li tinqara biss, capabilities imneħħija, u
  `no-new-privileges`;
- jużaw `/home/bridge` privat, volum dedikat għall-konfigurazzjoni ta' Claude, data ta' OmniRoute iżolata,
  u volum separat `devin-auth`;
- jimmuntaw biss workspaces/evidenza `.sandbox` li jistgħu jintremew;
- ma jimmuntawx il-home tal-host, Keychain, kredenzjali SSH jew tal-cloud, jew is-socket ta' Docker;
- jibnu ambjenti espliċiti u jneħħu l-varjabbli tal-API/OAuth/routing ta' Anthropic;
- jidderieġu l-inferenza ta' Claude Code biss lejn `http://omniroute:20128` b'ċavetta lokali biss.

Il-profil offline juża network intern. Fil-profil live, OmniRoute jilħaq l-endpoints uffiċjali ta'
Devin biss permezz ta' `network-guard`; destinazzjonijiet mhux relatati jiġu miċħuda.
Claude Code għandu gwardja separata għall-egress li tiċħad kollox u jista' jilħaq biss is-servizz
lokali OmniRoute permezz ta' `NO_PROXY`. Il-fajls tal-awditjar tal-gwardji jiġu mmuntati biss
mill-proċess tal-gwardja rispettiv tagħhom. L-iskripts jivverifikaw is-sjieda tal-fajls, il-mode,
l-għadd tal-links, u kull deċiżjoni qabel jesportaw evidenza mingħajr tokens.

Ħaddem il-prova tal-iżolament b'mod indipendenti:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

Din tivvalida t-topoloġija, il-mounts imsemmija, is-settings non-root/read-only, ir-routing lokali
espliċitu, in-nuqqas ta' varjabbli sensittivi tal-ambjent, in-nuqqas tas-socket ta' Docker,
l-aċċess imblukkat għal `api.anthropic.com` u `claude.ai`, l-għażla ta' fornitur Devin biss, u
falliment espliċitu meta l-backend ACP ma jkunx disponibbli.

## Konfigurazzjoni inizjali u użu normali

Ibni l-image ippinnjata:

```bash
./scripts/devin-bridge/build
```

Awtentika biss il-volum iżolat ta' Devin:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

Il-kmand tal-login juża l-fluss uffiċjali ta' token manwali maħsub għal ambjenti
remoti/container. Il-valur jiddaħħal direttament fil-prompt tas-CLI; ma jiġix mgħoddi bħala
argument tal-proċess, miktub f'Git, jew ikkupjat mill-host.

Niedi r-runtime iżolat ta' Claude Code:

```bash
./scripts/devin-bridge/launch
```

`launch` jerġa' jivverifika l-iżolament, l-awtentikazzjoni ta' Devin, u l-iskoperta tal-mudelli
qabel jibda Claude Code fil-container. Qatt ma jħaddem l-eżekutibbli Claude tal-host. L-aliases
tal-mudelli jistgħu jiġu ssettjati f'`.env.devin-bridge`; kull valur ikkonfigurat irid iżomm
il-prefiss `devin-cli-agentic/`.

## Kmandi ta' validazzjoni

Il-perkors offline riproduċibbli ma jeħtieġ ebda kont Devin u m'għandux Internet waqt ir-runtime:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

Il-perkors live awtentikat li jeħtieġ attivazzjoni espliċita huwa:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

Ir-runner live jistenna bejn xenarju u ieħor biex jevita li jiftaħ sessjonijiet ACP f'daqqa u
jivvalida eventi strutturati tal-stream ta' Claude minflok jafda dikjarazzjonijiet testwali. It-tliet
xenarji tiegħu jagħtu prova ta':

1. qari dirett tal-proġett u analiżi tad-difetti;
2. `Edit` reali, `Bash` `npm test` taħt il-kontroll tal-klijent, u riżultat terminali;
3. `/bridge-check` flimkien mal-iskoperta ta' `bridge-proof`, qari tal-proġett, `npm test` ieħor
   taħt il-kontroll tal-klijent li jirnexxi, u tlestija mingħajr xogħol pendenti.

Il-kontroll finali jivverifika wkoll l-awditjar tan-network ta' Devin u jirrikjedi li l-awditjar
tal-egress ta' Claude jibqa' vojt.

## Aġġornament tal-għodod b’verżjonijiet fissi

L-immaġni tiffissa l-verżjonijiet ta’ Node, Claude Code, u Devin CLI f’
`docker/devin-bridge/Dockerfile`. Biex taġġornahom:

1. ibdel il-verżjonijiet espliċiti;
2. issostitwixxi ż-żewġ checksums tal-arkivju ta’ Devin speċifiċi għall-arkitettura b’valuri għall-artifatt uffiċjali;
3. ibni mill-ġdid u ħaddem kull kmand ta’ validazzjoni offline;
4. ikkonferma l-verżjonijiet ġewwa l-immaġni;
5. erġa’ ħaddem is-sett live awtentikat ta’ tliet xenarji.

Tinstallax l-ebda waħda mis-CLI globalment fuq il-host u tissostitwixxix il-verifika taċ-checksum bi tniżżil mhux ivverifikat.

## Dijanjosi u tindif

- `docker compose -f docker/devin-bridge/compose.yml --profile offline logs omniroute`
  juri r-routing lokali u l-iżbalji sanitizzati tal-eżekutur.
- `.sandbox/evidence/mock-acp.jsonl` jirreġistra azzjonijiet mock ACP deterministiċi.
- `.sandbox/evidence/claude-stream.jsonl` jirreġistra l-eżekuzzjoni offline reali ta’ Claude Code.
- `.sandbox/evidence/live-*.jsonl` jirreġistra t-tliet flussi live vvalidati.
- `.sandbox/evidence/egress.jsonl` u `.sandbox/evidence/claude-egress.jsonl` huma kopji vvalidati u mingħajr tokens tal-awditi tal-guard.

Waqqaf il-containers u n-networks li huma proprjetà tal-bridge filwaqt li tippreserva l-volumes tal-login/konfigurazzjoni:

```bash
./scripts/devin-bridge/clean
```

Neħħi l-ambjent sħiħ li huwa proprjetà tal-bridge, inklużi l-volumes bl-isem:

```bash
./scripts/devin-bridge/clean --all
```

## Limitazzjonijiet

- Il-bridge jiddependi fuq ir-rwol fiss `summarizer` mingħajr għodod għax Devin CLI `3000.2.17`
  ma jesponix aġent ACP newtrali mingħajr għodod. L-adapter jikkumpensa għal tweġibiet intermedji
  f’għamla ta’ sommarju, iżda tentattiv wieħed limitat ta’ tiswija xorta jista’ jfalli b’mod espliċitu.
- Sejħiet ACP live jistgħu jirritornaw tweġibiet temporanji `502`/`504`. Il-harness iqassam ix-xenarji
  b’intervalli; falliment persistenti jibqa’ magħluq f’każ ta’ falliment u qatt ma jagħżel fornitur ieħor.
- Il-kuntest ACP jinbena mill-ġdid minn kull talba Anthropic; ma hemm l-ebda affinità
  tal-proċess/sessjoni.
- Sejħa waħda ta’ għodda hija appoġġjata għal kull tweġiba tal-mudell; sejħiet paralleli jiġu miċħuda.
- L-immaġnijiet espliċitament mhumiex appoġġjati. Il-viżjoni, l-output tal-ħsieb, il-kontrolli tal-isforz, u tieqa
  tal-kuntest ta’ 1M mhumiex reklamati.
- SSE juża avvenimenti validi taċ-ċiklu tal-ħajja ta’ Anthropic iżda jintbagħat wara li jinġabar it-turn limitat
  tal-ACP; il-biċċiet ACP ma jintbagħtux b’mod inkrementali.
