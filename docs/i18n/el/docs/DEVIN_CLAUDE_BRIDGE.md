Το `devin-cli-agentic` επιτρέπει στο πραγματικό runtime του Claude Code να χρησιμοποιεί το τοπικό endpoint Anthropic
Messages του OmniRoute, ενώ το επίσημο Devin CLI παρέχει αποκρίσεις μοντέλου μέσω ACP stdio. Δεν
τροποποιεί τους υπάρχοντες παρόχους Anthropic, Claude OAuth, Claude Web ή `devin-cli`.

Για κλήσεις εργαλείων που εκτελούνται από τον πελάτη, δρομολογήστε μέσω του `devin-cli-agentic` (ψευδώνυμο `dva`), του
παρόχου με μορφή Claude και υποστήριξη εργαλείων. Ο παλαιού τύπου εκτελεστής ACP `devin-cli` (`dv`) είναι
μόνο για κείμενο: εκτελεί το summarizer χωρίς εργαλεία του Devin και δεν μπορεί να επιστρέψει κλήσεις εργαλείων. Τα μεταδεδομένα
του μοντέλου του έχουν επισημανθεί αναλόγως, ώστε η συνδυαστική δρομολόγηση που απαιτεί εργαλεία να τον αποφεύγει.

> **Τρέχουσα κατάσταση: καρφιτσωμένο Claude Code `2.1.258`· η τελευταία καταγεγραμμένη επικύρωση εκτός σύνδεσης και σε πραγματικό περιβάλλον
> έγινε στην έκδοση `2.1.220`.** Το καρφίτσωμα της έκδοσης `2.1.220` ολοκλήρωσε τρία απομονωμένα σενάρια μέσω του Devin CLI
> `3000.2.17` και του μοντέλου `swe-1-7-lightning`· εκείνη η τελική εκτέλεση σε πραγματικό περιβάλλον απέδειξε γύρους `Read`,
> `Edit` και `Bash` που εκτελούνται από τον πελάτη, επιτυχή αποτελέσματα του `npm test`, εντοπισμό εντολών και δεξιοτήτων
> του έργου, δρομολόγηση αποκλειστικά μέσω Devin και μηδενική εξερχόμενη κίνηση προς το Claude. Στη συνέχεια, η καρφιτσωμένη έκδοση αναβαθμίστηκε στην `2.1.258`
> (τη γενιά του CLI την οποία μιμείται η ταυτότητα Claude του OmniRoute και την πρώτη σειρά που διαθέτει
> εγγενώς το επίπεδο Fable 5.1). Στη νέα καρφιτσωμένη έκδοση, το επίπεδο εγκατάστασης και το `claude --version`
> επαληθεύτηκαν στη βασική εικόνα με την καρφιτσωμένη έκδοση, ενώ η σουίτα δοκιμών μονάδας της γέφυρας, το `compose config` και η
> στατική απόδειξη απομόνωσης ολοκληρώνονται επιτυχώς — όμως το σενάριο προσομοίωσης εκτός σύνδεσης και η σουίτα τριών σεναρίων
> σε πραγματικό περιβάλλον δεν έχουν εκτελεστεί ξανά ακόμη. Εκτελέστε τα ξανά (βλ. «Ενημέρωση καρφιτσωμένων εργαλείων») πριν βασιστείτε
> στη γέφυρα με αυτήν την καρφιτσωμένη έκδοση.

## Αρχιτεκτονική

```text
Claude Code 2.1.258 (απομονωμένο κοντέινερ Linux χωρίς δικαιώματα root)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (μορφή Claude, πάροχος χωρίς έλεγχο ταυτότητας)
  -> devin acp --agent-type summarizer (επίσημο ACP stdio, χωρίς εργαλεία Devin)
  -> λογαριασμός Devin στον αποκλειστικό τόμο devin-auth
```

Ο προεπιλεγμένος πράκτορας ACP του επίσημου CLI μπορεί να εκτελεί τα δικά του εργαλεία, επομένως αυτή η γέφυρα δεν
τον χρησιμοποιεί. Εκκινεί τον σταθερό πράκτορα ACP `summarizer`, του οποίου η επίσημη λειτουργία CLI δεν διαθέτει εργαλεία, και
πλαισιώνει το σειριοποιημένο αίτημα Anthropic ως ίχνος εκτέλεσης. Όταν απαιτείται άλλη ενέργεια που εκτελείται από το Claude,
η απόκριση πρέπει να περιέχει ακριβώς έναν φάκελο εργαλείου πελάτη. Κάθε ACP
`tool_call` ή `tool_call_update` απορρίπτεται προτού μια απόκριση μπορέσει να αναφερθεί ως
επιτυχής.

Ο σειριοποιητής στο `open-sse/executors/devin-agentic/serializer.ts` διατηρεί τα `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice` και τα
εργαλεία που παρέχονται από το Claude Code. Οι εικόνες και τα άγνωστα μπλοκ αποτυγχάνουν ρητά. Τα μεγάλα αποτελέσματα εργαλείων
χρησιμοποιούν έναν ορατό δείκτη περικοπής.

Ο αναλυτής δέχεται έναν αυτόνομο φάκελο `<tool>{...}</tool>` ανά γύρο του μοντέλου. Ελέγχει
το όνομα σε σχέση με τη λίστα εργαλείων του αιτήματος, επικυρώνει τα ορίσματα βάσει του JSON
Schema αυτού του εργαλείου, απορρίπτει μικτές αφηγήσεις/ενέργειες και επιτρέπει μία περιορισμένη επιδιόρθωση. Στη συνέχεια, το Claude Code
εκτελεί το προκύπτον Anthropic `tool_use` τοπικά και στέλνει το `tool_result` πίσω μέσω
του OmniRoute.

## Αυτόματη δρομολόγηση

Ο πάροχος είναι επιλέξιμος στις ομάδες υποψηφίων `auto/*` του OmniRoute όταν δεν είναι αποκλεισμένος.
Η επιλεξιμότητα ενός υποψηφίου δεν εγγυάται την επιλογή του: η στρατηγική δρομολόγησης του συνδυασμού (για παράδειγμα,
η τελευταία γνωστή έγκυρη επιλογή) μπορεί να προτιμήσει άλλον πάροχο. Χρησιμοποιήστε το `dva/<model>` ή έναν συνδυασμό με προτεραιότητα στο Devin όταν
απαιτείτε κάθε αίτημα να περνά μέσω του Devin.

## Απομόνωση και μοντέλο απειλών

Η εγκατάσταση, ο λογαριασμός και η διαμόρφωση του Claude στον κεντρικό υπολογιστή είναι εκτός πεδίου εφαρμογής και θεωρούνται απαγορευμένα. Οι υπηρεσίες Compose:

- εκτελούνται ως UID/GID `10001:10001`, με σύστημα αρχείων ρίζας μόνο για ανάγνωση, καταργημένες δυνατότητες και
  `no-new-privileges`;
- χρησιμοποιούν έναν ιδιωτικό κατάλογο `/home/bridge`, έναν αποκλειστικό τόμο διαμόρφωσης του Claude, απομονωμένα δεδομένα OmniRoute
  και έναν ξεχωριστό τόμο `devin-auth`;
- προσαρτούν μόνο αναλώσιμους χώρους εργασίας/τεκμήρια `.sandbox`;
- δεν προσαρτούν τον προσωπικό κατάλογο του κεντρικού υπολογιστή, το Keychain, διαπιστευτήρια SSH, διαπιστευτήρια cloud ή το Docker socket;
- δημιουργούν ρητά περιβάλλοντα και αφαιρούν μεταβλητές API/OAuth/δρομολόγησης του Anthropic;
- κατευθύνουν τη συμπερασματολογία του Claude Code μόνο στο `http://omniroute:20128` με ένα κλειδί αποκλειστικά για τοπική χρήση.

Το προφίλ εκτός σύνδεσης χρησιμοποιεί εσωτερικό δίκτυο. Στο ζωντανό προφίλ, το OmniRoute προσπελαύνει τα
επίσημα τελικά σημεία του Devin μόνο μέσω του `network-guard`· οι μη σχετικοί προορισμοί απορρίπτονται.
Το Claude Code διαθέτει ξεχωριστό μηχανισμό προστασίας εξερχόμενης κίνησης που την απορρίπτει πλήρως και μπορεί να προσπελάσει μόνο την τοπική υπηρεσία OmniRoute
μέσω του `NO_PROXY`. Τα αρχεία ελέγχου των μηχανισμών προστασίας προσαρτώνται μόνο από τη διεργασία του αντίστοιχου μηχανισμού προστασίας. Τα
scripts επαληθεύουν την ιδιοκτησία, τη λειτουργία, τον αριθμό συνδέσμων και κάθε απόφαση για τα αρχεία, πριν εξαγάγουν
τεκμήρια χωρίς διακριτικά.

Εκτελέστε ανεξάρτητα την απόδειξη απομόνωσης:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

Επικυρώνει την τοπολογία, τις επώνυμες προσαρτήσεις, τις ρυθμίσεις εκτέλεσης χωρίς δικαιώματα root/μόνο για ανάγνωση, τη ρητή τοπική δρομολόγηση,
την απουσία ευαίσθητων μεταβλητών περιβάλλοντος, την απουσία του Docker socket, τον αποκλεισμό πρόσβασης στα
`api.anthropic.com` και `claude.ai`, την επιλογή παρόχου αποκλειστικά για το Devin και τη ρητή αποτυχία όταν
το backend ACP δεν είναι διαθέσιμο.

## Αρχική ρύθμιση και κανονική χρήση

Δημιουργήστε την καρφιτσωμένη εικόνα:

```bash
./scripts/devin-bridge/build
```

Πραγματοποιήστε έλεγχο ταυτότητας μόνο στον απομονωμένο τόμο του Devin:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

Η εντολή σύνδεσης χρησιμοποιεί την επίσημη ροή χειροκίνητου διακριτικού που προορίζεται για απομακρυσμένα περιβάλλοντα/περιβάλλοντα
κοντέινερ. Η τιμή εισάγεται απευθείας στην προτροπή του CLI· δεν μεταβιβάζεται ως
όρισμα διεργασίας, δεν εγγράφεται στο Git και δεν αντιγράφεται από τον κεντρικό υπολογιστή.

Εκκινήστε το απομονωμένο περιβάλλον εκτέλεσης του Claude Code:

```bash
./scripts/devin-bridge/launch
```

Το `launch` επανελέγχει την απομόνωση, τον έλεγχο ταυτότητας του Devin και τον εντοπισμό μοντέλων πριν εκκινήσει το
Claude Code εντός κοντέινερ. Δεν εκτελεί ποτέ το εκτελέσιμο αρχείο Claude του κεντρικού υπολογιστή. Τα ψευδώνυμα μοντέλων μπορούν να
οριστούν στο `.env.devin-bridge`· κάθε διαμορφωμένη τιμή πρέπει να διατηρεί το πρόθεμα
`devin-cli-agentic/`.

## Εντολές επικύρωσης

Η αναπαραγώγιμη διαδρομή εκτός σύνδεσης δεν απαιτεί λογαριασμό Devin και δεν χρησιμοποιεί το διαδίκτυο κατά την εκτέλεση:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

Η προαιρετική ζωντανή διαδρομή με έλεγχο ταυτότητας είναι:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

Το πρόγραμμα εκτέλεσης ζωντανών δοκιμών περιμένει μεταξύ των σεναρίων, ώστε να αποφεύγεται το ταυτόχρονο άνοιγμα πολλών συνεδριών ACP, και
επικυρώνει δομημένα συμβάντα ροής του Claude αντί να εμπιστεύεται ισχυρισμούς σε μορφή κειμένου. Τα τρία
σενάριά του αποδεικνύουν:

1. άμεσες αναγνώσεις του έργου και ανάλυση ελαττωμάτων·
2. ένα πραγματικό `Edit`, ένα `Bash` `npm test` υπό τον έλεγχο του πελάτη και ένα τερματικό αποτέλεσμα·
3. εντοπισμό των `/bridge-check` και `bridge-proof`, αναγνώσεις του έργου, άλλη μία επιτυχή
   εκτέλεση `npm test` υπό τον έλεγχο του πελάτη και ολοκλήρωση χωρίς εκκρεμείς εργασίες.

Η τελική πύλη ελέγχει επίσης τον έλεγχο δικτύου του Devin και απαιτεί ο έλεγχος εξερχόμενης κίνησης του Claude να
παραμένει κενός.

## Ενημέρωση καρφιτσωμένων εργαλείων

Η εικόνα καρφιτσώνει τα Node, Claude Code και Devin CLI στο
`docker/devin-bridge/Dockerfile`. Για ενημέρωση:

1. αλλάξτε τις ρητά καθορισμένες εκδόσεις·
2. αντικαταστήστε τα αθροίσματα ελέγχου του αρχείου Devin και για τις δύο συγκεκριμένες αρχιτεκτονικές με τιμές για το επίσημο
   τεχνούργημα·
3. ανακατασκευάστε και εκτελέστε κάθε εντολή επικύρωσης εκτός σύνδεσης·
4. επιβεβαιώστε τις εκδόσεις μέσα στην εικόνα·
5. εκτελέστε ξανά την πιστοποιημένη ζωντανή σουίτα τριών σεναρίων.

Μην εγκαταστήσετε κανένα από τα δύο CLI καθολικά στο σύστημα υποδοχής και μην αντικαταστήσετε την επαλήθευση αθροίσματος ελέγχου με
μη επαληθευμένη λήψη.

## Διάγνωση και εκκαθάριση

- Η εντολή `docker compose -f docker/devin-bridge/compose.yml --profile offline logs omniroute`
  εμφανίζει την τοπική δρομολόγηση και τα αποκαθαρμένα σφάλματα του εκτελεστή.
- Το `.sandbox/evidence/mock-acp.jsonl` καταγράφει ντετερμινιστικές εικονικές ενέργειες ACP.
- Το `.sandbox/evidence/claude-stream.jsonl` καταγράφει την πραγματική εκτέλεση του Claude Code εκτός σύνδεσης.
- Το `.sandbox/evidence/live-*.jsonl` καταγράφει τις τρεις επικυρωμένες ζωντανές ροές.
- Τα `.sandbox/evidence/egress.jsonl` και `.sandbox/evidence/claude-egress.jsonl` είναι επικυρωμένα,
  χωρίς διακριτικά πρόσβασης αντίγραφα των ελέγχων εξερχόμενης κίνησης.

Σταματήστε τα ιδιόκτητα κοντέινερ και δίκτυα, διατηρώντας τους τόμους σύνδεσης/διαμόρφωσης:

```bash
./scripts/devin-bridge/clean
```

Καταργήστε ολόκληρο το περιβάλλον που ανήκει στη γέφυρα, συμπεριλαμβανομένων των ονομασμένων τόμων:

```bash
./scripts/devin-bridge/clean --all
```

## Περιορισμοί

- Η γέφυρα βασίζεται στον σταθερό ρόλο `summarizer` χωρίς εργαλεία, επειδή το Devin CLI `3000.2.17`
  δεν εκθέτει έναν ουδέτερο πράκτορα ACP χωρίς εργαλεία. Ο προσαρμογέας αντισταθμίζει τις ενδιάμεσες
  απαντήσεις με μορφή σύνοψης, αλλά μία οριοθετημένη επιδιόρθωση μπορεί ακόμη να αποτύχει ρητά.
- Οι ζωντανές κλήσεις ACP μπορούν να επιστρέψουν παροδικές αποκρίσεις `502`/`504`. Η υποδομή δοκιμών αφήνει χρονικά διαστήματα μεταξύ των σεναρίων·
  η επίμονη αποτυχία παραμένει σε κατάσταση ασφαλούς αποτυχίας και δεν επιλέγει ποτέ άλλον πάροχο.
- Το πλαίσιο ACP ανακατασκευάζεται από κάθε αίτημα Anthropic· δεν υπάρχει συσχέτιση με διεργασία/συνεδρία.
- Υποστηρίζεται μία κλήση εργαλείου ανά απόκριση μοντέλου· οι παράλληλες κλήσεις απορρίπτονται.
- Οι εικόνες δεν υποστηρίζονται ρητά. Δεν διαφημίζονται δυνατότητες όρασης, έξοδος συλλογισμού, στοιχεία ελέγχου προσπάθειας και
  παράθυρο περιβάλλοντος 1M.
- Το SSE χρησιμοποιεί έγκυρα συμβάντα κύκλου ζωής Anthropic, αλλά εκπέμπεται αφού συλλεχθεί η οριοθετημένη σειρά ενεργειών ACP·
  τα τμήματα ACP δεν προωθούνται σταδιακά.
