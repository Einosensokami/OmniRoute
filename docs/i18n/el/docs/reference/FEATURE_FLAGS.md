> Εναλλαγές κατά την εκτέλεση που αλλάζουν τη συμπεριφορά του OmniRoute **χωρίς νέα ανάπτυξη**.
> Κάθε σημαία που παρατίθεται εδώ ορίζεται στο
> [`src/shared/constants/featureFlagDefinitions.ts`](../../src/shared/constants/featureFlagDefinitions.ts)
> — τη μοναδική πηγή αλήθειας. Τόσο ο πίνακας ελέγχου όσο και το REST API διαβάζουν από
> αυτό το αρχείο, επομένως ο παρακάτω πίνακας δημιουργείται ώστε να αντιστοιχεί σε αυτό 1:1.

---

## Τι Είναι οι Σημαίες Δυνατοτήτων

Μια σημαία δυνατότητας είναι μια επώνυμη εναλλαγή (boolean ή enum), η τιμή της οποίας μπορεί να αλλάξει κατά
την εκτέλεση και να αποθηκευτεί στη βάση δεδομένων, χωρίς να απαιτείται νέα ανάπτυξη της διεργασίας. Κάθε
σημαία περιγράφεται από ένα `FeatureFlagDefinition` με `key`, `label`,
`description`, `category`, `defaultValue`, `type` και μια ένδειξη `requiresRestart`.

### Σειρά Επίλυσης

Η **ενεργή τιμή** μιας σημαίας επιλύεται από τη
[`resolveFeatureFlag()`](../../src/shared/utils/featureFlags.ts) με την ακόλουθη
σειρά προτεραιότητας (υπερισχύει η υψηλότερη):

1. **Παράκαμψη βάσης δεδομένων** — μια τιμή αποθηκευμένη στον πίνακα `key_value` στον
   χώρο ονομάτων `feature_flags` (ορίζεται μέσω του πίνακα ελέγχου ή του REST API).
2. **Μεταβλητή περιβάλλοντος** — `process.env[<KEY>]`, εφόσον έχει οριστεί και δεν είναι κενή.
3. **Προεπιλογή ορισμού** — η `defaultValue` από το `featureFlagDefinitions.ts`.

Μια σημαία boolean θεωρείται **ενεργοποιημένη** όταν η ενεργή τιμή της είναι `"true"`,
`"1"` ή `"yes"` (βλ. `isFeatureFlagEnabled()`).

> [!NOTE]
> Οι περισσότερες σημαίες διαθέτουν επίσης μια αντίστοιχη μεταβλητή περιβάλλοντος με το **ίδιο όνομα**,
> η οποία τεκμηριώνεται στο [`ENVIRONMENT.md`](./ENVIRONMENT.md). Η παράκαμψη της σημαίας στη βάση δεδομένων
> έχει προτεραιότητα έναντι αυτής της μεταβλητής περιβάλλοντος. Μια σημαία με
> `requiresRestart: true` αποθηκεύεται αμέσως, αλλά διαβάζεται ξανά μόνο κατά την εκκίνηση της
> διεργασίας — η αλλαγή της εμφανίζει ένα πλαίσιο **"Επανεκκίνηση Διακομιστή"** στον πίνακα ελέγχου.

## Εναλλαγή σημαιών

### Πίνακας ελέγχου

Μεταβείτε στο **Πίνακας ελέγχου → Ρυθμίσεις → Σημαίες λειτουργιών**
(`/dashboard/settings/feature-flags`). Το πλέγμα
(`src/app/(dashboard)/dashboard/settings/components/FeatureFlagsGrid.tsx`)
υποστηρίζει:

- **Αναζήτηση** βάσει κλειδιού ή περιγραφής και **φιλτράρισμα** βάσει κατηγορίας (καθώς και μια συνθετική
  προβολή **Απαιτεί επανεκκίνηση**).
- Έναν **διακόπτη εναλλαγής** για σημαίες τύπου boolean και μια **αναπτυσσόμενη λίστα** για σημαίες τύπου enum
  (`src/app/(dashboard)/dashboard/settings/components/FeatureFlagCard.tsx`).
- Ένα **σήμα προέλευσης** ανά σημαία — `DB`, `ENV` ή `DEF` — που δείχνει από πού
  προήλθε η ενεργή τιμή.
- Ένα κουμπί **Επαναφορά** (εμφανίζεται μόνο για σημαίες που προέρχονται από `DB`) για την κατάργηση της παράκαμψης,
  καθώς και ένα κουμπί **Επαναφορά όλων των παρακάμψεων** στο κάτω μέρος.
- Ένα πλαίσιο ειδοποίησης **Επανεκκίνηση διακομιστή** όταν αλλάζει μια σημαία `requiresRestart`.

### REST API

Όλες οι λειτουργίες εκτελούνται μέσω μίας μόνο διαδρομής:
[`src/app/api/settings/feature-flags/route.ts`](../../src/app/api/settings/feature-flags/route.ts).
Κάθε μέθοδος απαιτεί πιστοποιημένη συνεδρία πίνακα ελέγχου (διαφορετικά επιστρέφεται `401`).

#### `GET /api/settings/feature-flags`

Επιστρέφει κάθε σημαία μαζί με την ενεργή τιμή, την προέλευση και μια σύνοψη.

```jsonc
{
  "flags": [
    {
      "key": "REQUIRE_API_KEY",
      "label": "Require API Key",
      "description": "Require an API key for all incoming requests",
      "category": "security",
      "type": "boolean",
      "enumValues": null,
      "defaultValue": "false",
      "effectiveValue": "false",
      "source": "default", // "db" | "env" | "default"
      "requiresRestart": false,
      "warningLevel": "caution",
    },
    // ... και οι 108 σημαίες
  ],
  "summary": {
    "total": 56,
    "active": 0,
    "inactive": 0,
    "overriddenByDb": 0,
    "overriddenByEnv": 0,
  },
}
```

#### `PUT /api/settings/feature-flags`

Ορίζει ή καταργεί μία μεμονωμένη παράκαμψη. Σώμα: `{ key: string; value?: string }`.
Η παράλειψη του `value` καταργεί την παράκαμψη (επαναφέροντας την τιμή env / προεπιλογής).

```bash
# Ορισμός παράκαμψης στη βάση δεδομένων
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY","value":"true"}'

# Κατάργηση της παράκαμψης (χωρίς "value")
curl -X PUT http://localhost:20128/api/settings/feature-flags \
  -H "Content-Type: application/json" \
  -d '{"key":"REQUIRE_API_KEY"}'
```

Η απόκριση επιστρέφει τη νέα `effectiveValue`/`source`, την `previousValue`/
`previousSource` και το `requiresRestart`. Άγνωστα κλειδιά και τιμές enum εκτός
του επιτρεπόμενου εύρους απορρίπτονται με `400`.

#### `DELETE /api/settings/feature-flags`

Καταργεί **όλες** τις παρακάμψεις της βάσης δεδομένων ταυτόχρονα, επαναφέροντας κάθε σημαία στην τιμή
env / προεπιλογής της. Επιστρέφει `{ cleared: <count>, message: "..." }`.

> [!NOTE]
> Οι σημαίες με `requiresRestart: true` τίθενται σε ισχύ μόνο μετά την επανεκκίνηση της διεργασίας.
> Η ροή επανεκκίνησης του πίνακα ελέγχου καλεί το `POST /api/restart` και στη συνέχεια εκτελεί επαναλαμβανόμενα αιτήματα στο
> `GET /api/health/ping` έως ότου ο διακομιστής τεθεί ξανά σε λειτουργία.

## Εφεδρική Λύση Έκτακτης Ανάγκης για τον Προϋπολογισμό

Η `OMNIROUTE_EMERGENCY_FALLBACK` (κατηγορία `runtime`, προεπιλογή `true`) ελέγχει τη
δωρεάν διαδρομή εφεδρικής λύσης έκτακτης ανάγκης στο
[`open-sse/services/emergencyFallback.ts`](../../open-sse/services/emergencyFallback.ts).
Όταν είναι ενεργοποιημένη, τα αιτήματα που εξαντλούν τον προϋπολογισμό τους δρομολογούνται σε έναν δωρεάν εφεδρικό
πάροχο/μοντέλο αντί να αποτυγχάνουν πλήρως. Ορίστε την σε `false` (ή `0`) — μέσω του
διακόπτη στον πίνακα ελέγχου, μιας παράκαμψης στη βάση δεδομένων ή της μεταβλητής περιβάλλοντος
`OMNIROUTE_EMERGENCY_FALLBACK` — για να απενεργοποιήσετε αυτήν τη συμπεριφορά και να επιτρέψετε στα αιτήματα που έχουν εξαντλήσει τον προϋπολογισμό τους
να αποτυγχάνουν. (Εμφανίζεται ως διακόπτης στον πίνακα ελέγχου στα PR #3741 / #3752.)

Μια απόκριση που εξυπηρετείται από αυτήν την εφεδρική λύση περιλαμβάνει την κεφαλίδα
`X-OmniRoute-Emergency-Fallback: from=<provider/model>; to=<provider/model>`, ώστε ένας
πελάτης να μπορεί να διαπιστώσει ότι αναδρομολογήθηκε χωρίς να συγκρίνει την `X-OmniRoute-Provider` με το
αίτημά του. Η κεφαλίδα απουσιάζει από κάθε άλλη απόκριση.
