`devin-cli-agentic` leidžia tikrajai Claude Code vykdymo aplinkai naudoti OmniRoute vietinį Anthropic
Messages galinį punktą, o oficiali Devin CLI pateikia modelio atsakymus per ACP stdio. Ji
nekeičia esamų Anthropic, Claude OAuth, Claude Web ar `devin-cli` teikėjų.

Kliento valdomiems įrankių iškvietimams maršrutizuokite per `devin-cli-agentic` (alternatyvus pavadinimas `dva`) —
Claude formato teikėją, palaikantį įrankius. Senasis `devin-cli` (`dv`) ACP vykdytojas
palaiko tik tekstą: jis paleidžia Devin apibendrinimo komponentą be įrankių ir negali grąžinti įrankių iškvietimų. Jo modelio
metaduomenys yra atitinkamai pažymėti, todėl sudėtinis maršrutizavimas, kuriam būtini įrankiai, jo vengs.

> **Dabartinė būsena: naudojama fiksuota Claude Code `2.1.258` versija; paskutinis autonominis ir tiesioginis tikrinimas
> užregistruotas naudojant `2.1.220`.** Naudojant fiksuotą `2.1.220` versiją buvo įvykdyti trys izoliuoti scenarijai per Devin CLI
> `3000.2.17` ir modelį `swe-1-7-lightning`; tas galutinis tiesioginis vykdymas patvirtino kliento valdomus `Read`,
> `Edit` ir `Bash` etapus, sėkmingus `npm test` rezultatus, projekto komandų bei įgūdžių
> aptikimą, tik per Devin vykdomą maršrutizavimą ir nulinį duomenų perdavimą į Claude. Tada fiksuota versija buvo pakelta iki `2.1.258`
> (CLI kartos, kuria apsimeta OmniRoute Claude tapatybė, ir pirmosios versijos, kuri savaime pateikiama
> su Fable 5.1 lygiu). Naudojant naują fiksuotą versiją, diegimo sluoksnis ir `claude --version` buvo
> patikrinti fiksuotame baziniame atvaizde, o tilto modulių testų rinkinys, `compose config` ir
> statinis izoliavimo įrodymas yra sėkmingi, tačiau autonominis imitacinis scenarijus ir tiesioginis trijų scenarijų
> testų rinkinys dar nebuvo paleisti iš naujo. Prieš pasikliaudami tiltu su šia fiksuota versija, paleiskite juos iš naujo
> (žr. „Fiksuotų įrankių atnaujinimas“).

## Architektūra

```text
Claude Code 2.1.258 (izoliuotas ne root naudotojo Linux konteineris)
  -> http://omniroute:20128/v1/messages
  -> devin-cli-agentic (Claude formatas, autentifikavimo nereikalaujantis teikėjas)
  -> devin acp --agent-type summarizer (oficialus ACP stdio, be Devin įrankių)
  -> Devin paskyra tam skirtame devin-auth tome
```

Oficialios CLI numatytasis ACP agentas gali vykdyti savo įrankius, todėl šis tiltas jo
nenaudoja. Jis paleidžia fiksuotą `summarizer` ACP agentą, kurio oficialus CLI režimas neturi įrankių, ir
suformuoja serializuotą Anthropic užklausą kaip vykdymo seką. Kai reikia kito Claude valdomo
veiksmo, atsakyme turi būti tiksliai vienas kliento įrankio apvalkalas. Bet koks ACP
`tool_call` arba `tool_call_update` atmetamas prieš atsakymą pažymint kaip
sėkmingą.

Serializatorius faile `open-sse/executors/devin-agentic/serializer.ts` išsaugo `system`,
`text`, `tool_use`, `tool_result`, `thinking`, `redacted_thinking`, `tool_choice` ir
Claude Code pateiktus įrankius. Vaizdai ir nežinomi blokai aiškiai atmetami. Dideliuose įrankių rezultatuose
naudojama matoma sutrumpinimo žyma.

Analizatorius priima vieną atskirą `<tool>{...}</tool>` apvalkalą kiekviename modelio etape. Jis patikrina
pavadinimą pagal užklausos įrankių sąrašą, patikrina argumentus pagal to įrankio JSON
schemą, atmeta sumaišytą pasakojimą ir veiksmus bei leidžia vieną ribotą taisymą. Tada Claude Code
vietoje įvykdo gautą Anthropic `tool_use` ir siunčia `tool_result` atgal per
OmniRoute.

## Automatinis maršrutizavimas

Kai teikėjas nėra užblokuotas, jis gali būti įtrauktas į OmniRoute `auto/*` kandidatų telkinius.
Tinkamumas būti kandidatu negarantuoja pasirinkimo: sudėtinio maršruto strategija (pavyzdžiui,
paskutinis sėkmingas variantas) gali teikti pirmenybę kitam teikėjui. Naudokite `dva/<model>` arba sudėtinį maršrutą, kuriame
pirmenybė teikiama Devin, kai reikalaujate, kad kiekviena užklausa būtų siunčiama per Devin.

## Izoliavimas ir grėsmių modelis

Pagrindinio kompiuterio „Claude“ diegimas, paskyra ir konfigūracija nepatenka į taikymo sritį ir yra laikomi
draudžiamais. „Compose“ paslaugos:

- veikia su UID/GID `10001:10001`, tik skaitoma šaknine failų sistema, pašalintomis galimybėmis ir
  `no-new-privileges`;
- naudoja privatų `/home/bridge`, atskirą „Claude“ konfigūracijos tomą, izoliuotus „OmniRoute“ duomenis
  ir atskirą `devin-auth` tomą;
- prijungia tik vienkartines `.sandbox` darbo sritis / įrodymus;
- neprijungia pagrindinio kompiuterio namų katalogo, „Keychain“, SSH, debesijos prisijungimo duomenų ar „Docker“ lizdo;
- sukuria aiškiai apibrėžtas aplinkas ir pašalina „Anthropic“ API / OAuth / maršruto parinkimo kintamuosius;
- nukreipia „Claude Code“ išvadų generavimą tik į `http://omniroute:20128`, naudodamos tik vietinį raktą.

Neprisijungęs profilis naudoja vidinį tinklą. Tiesioginio ryšio profilyje „OmniRoute“ oficialius
„Devin“ galinius taškus pasiekia tik per `network-guard`; nesusijusios paskirties vietos yra atmetamos.
„Claude Code“ turi atskirą visą išeinantį srautą blokuojančią apsaugą ir gali pasiekti tik vietinę „OmniRoute“
paslaugą per `NO_PROXY`. Apsaugos audito failus prijungia tik atitinkamas apsaugos procesas. Scenarijai
patikrina failų savininkus, režimą, nuorodų skaičių ir kiekvieną sprendimą prieš eksportuodami
įrodymus be prieigos raktų.

Paleiskite izoliavimo patikrą atskirai:

```bash
./scripts/devin-bridge/verify-anthropic-isolation
```

Ji patikrina topologiją, vardinius prijungimus, ne „root“ naudotojo / tik skaitymo nustatymus, aiškiai apibrėžtą vietinį maršruto parinkimą,
jautrių aplinkos kintamųjų nebuvimą, „Docker“ lizdo nebuvimą, užblokuotą prieigą prie
`api.anthropic.com` ir `claude.ai`, tik „Devin“ teikėjo pasirinkimą ir aiškiai apibrėžtą nesėkmę, kai
ACP galinė sistema nepasiekiama.

## Pradinė sąranka ir įprastas naudojimas

Sukurkite prie konkrečių versijų priskirtą atvaizdą:

```bash
./scripts/devin-bridge/build
```

Autentifikuokite tik izoliuotą „Devin“ tomą:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/login-devin
```

Prisijungimo komanda naudoja oficialų rankinį prieigos rakto procesą, skirtą nuotolinėms / konteinerių
aplinkoms. Reikšmė įvedama tiesiogiai CLI raginime; ji neperduodama kaip
proceso argumentas, neįrašoma į „Git“ ir nekopijuojama iš pagrindinio kompiuterio.

Paleiskite izoliuotą „Claude Code“ vykdymo aplinką:

```bash
./scripts/devin-bridge/launch
```

`launch` prieš paleisdama konteineryje veikiantį „Claude Code“ iš naujo patikrina izoliavimą, „Devin“ autentifikavimą ir modelių aptikimą.
Ji niekada nepaleidžia pagrindinio kompiuterio „Claude“ vykdomojo failo. Modelių alternatyviuosius pavadinimus galima
nustatyti faile `.env.devin-bridge`; kiekviena sukonfigūruota reikšmė turi išlaikyti
`devin-cli-agentic/` prefiksą.

## Tikrinimo komandos

Atkuriamam neprisijungus vykdomam procesui nereikia „Devin“ paskyros ir vykdymo metu nereikia interneto:

```bash
./scripts/devin-bridge/test-unit
./scripts/devin-bridge/test-contract
./scripts/devin-bridge/test-e2e-mock
./scripts/devin-bridge/verify-anthropic-isolation
```

Pasirenkamas autentifikuotas tiesioginio ryšio procesas yra:

```bash
ENABLE_LIVE_DEVIN_TESTS=1 ./scripts/devin-bridge/test-live-devin
```

Tiesioginio ryšio vykdyklė laukia tarp scenarijų, kad ACP sesijos nebūtų atidaromos pliūpsniu, ir
tikrina struktūrizuotus „Claude“ srauto įvykius, užuot pasitikėjusi tekstiniais teiginiais. Trys jos
scenarijai įrodo:

1. tiesioginį projekto failų skaitymą ir defektų analizę;
2. tikrą `Edit`, klientui priklausantį `Bash` `npm test` ir galutinį rezultatą;
3. `/bridge-check` bei `bridge-proof` aptikimą, projekto failų skaitymą, dar vieną sėkmingą
   klientui priklausantį `npm test` ir užbaigimą be laukiančių darbų.

Galutinis kontrolinis etapas taip pat patikrina „Devin“ tinklo auditą ir reikalauja, kad „Claude“ išeinančio srauto auditas
liktų tuščias.

## Prisegtų įrankių atnaujinimas

Atvaizde Node, Claude Code ir Devin CLI versijos yra prisegtos faile
`docker/devin-bridge/Dockerfile`. Norėdami atnaujinti:

1. pakeiskite aiškiai nurodytas versijas;
2. pakeiskite abiejų architektūrų Devin archyvų kontrolines sumas oficialaus
   artefakto reikšmėmis;
3. iš naujo sukurkite atvaizdą ir paleiskite visas autonominio tikrinimo komandas;
4. patvirtinkite versijas atvaizdo viduje;
5. iš naujo paleiskite autentifikuotą trijų scenarijų tiesioginių testų rinkinį.

Neįdiekite nė vienos CLI visuotinai pagrindinėje sistemoje ir nepakeiskite kontrolinės sumos tikrinimo
nepatikrintu atsisiuntimu.

## Diagnostika ir valymas

- `docker compose -f docker/devin-bridge/compose.yml --profile offline logs omniroute`
  rodo vietinį maršrutizavimą ir nuasmenintas vykdyklės klaidas.
- `.sandbox/evidence/mock-acp.jsonl` registruoja deterministinius imitacinio ACP veiksmus.
- `.sandbox/evidence/claude-stream.jsonl` registruoja tikrą autonominį Claude Code paleidimą.
- `.sandbox/evidence/live-*.jsonl` registruoja tris patikrintus tiesioginius srautus.
- `.sandbox/evidence/egress.jsonl` ir `.sandbox/evidence/claude-egress.jsonl` yra patikrintos,
  prieigos raktų neturinčios apsaugos auditų kopijos.

Sustabdykite valdomus konteinerius ir tinklus, išsaugodami prisijungimo / konfigūracijos tomus:

```bash
./scripts/devin-bridge/clean
```

Pašalinkite visą tiltui priklausančią aplinką, įskaitant vardinius tomus:

```bash
./scripts/devin-bridge/clean --all
```

## Apribojimai

- Tiltas remiasi fiksuota, įrankių neturinčia `summarizer` role, nes Devin CLI `3000.2.17`
  nepateikia neutralaus, įrankių neturinčio ACP agento. Adapteris kompensuoja santraukos formos
  tarpinius atsakymus, tačiau vienas apribotas taisymas vis tiek gali baigtis aiškia nesėkme.
- Tiesioginiai ACP iškvietimai gali grąžinti laikinas `502`/`504` būsenas. Testavimo sistema daro tarpus tarp scenarijų;
  nuolatinio gedimo atveju sistema lieka saugiai uždaryta ir niekada nepasirenka kito teikėjo.
- ACP kontekstas atkuriamas iš kiekvienos Anthropic užklausos; nėra susiejimo su procesu ar seansu.
- Viename modelio atsakyme palaikomas vienas įrankio iškvietimas; lygiagretūs iškvietimai atmetami.
- Vaizdai aiškiai nepalaikomi. Vaizdų analizė, mąstymo išvestis, pastangų valdikliai ir 1M
  konteksto langas nėra deklaruojami.
- SSE naudoja galiojančius Anthropic gyvavimo ciklo įvykius, tačiau jie siunčiami surinkus apribotą ACP etapą;
  ACP dalys nėra persiunčiamos palaipsniui.
